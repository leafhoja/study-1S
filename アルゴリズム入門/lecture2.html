第2回 数値表現と計算誤差

整数・二の補数・浮動小数点と、誤差を避ける式変形

地引昌弘 · 1A · 2026年10月15日

第2回の講義資料に基づく解説。数値の表現と演算の精度を区別し、演習で理由を確かめる。
1. 前回演習：タプル・剰余・インデント2. 位取りと小数の二進表現3. 符号なし整数と二の補数4. 浮動小数点と整数除算5. 丸め誤差・情報落ち・桁落ち6. 演習2-1〜2-4の解答7. 復習と参考

1. 前回演習：タプル・剰余・インデント

Pythonではインデントがブロックの範囲そのものを決める。return の字下げを変えれば、繰り返しの途中で関数が終了することもある。

def plus_minus(x, y):
    return x + y, x - y

def multiply(x, y):
    return x * y

a, b = plus_minus(5, 3)
multiply(a, b)                 # 16
multiply(*plus_minus(5, 3))    # 16

タプルを1個の引数として渡す multiply(plus_minus(5,3)) では、引数が2個必要な関数に1個しか渡らない。* は関数呼び出しで要素を展開する記法。複数代入による展開も使える。

負数の剰余と整数商整数商は $q=\lfloor x/y\rfloor$、剰余は $r=x-qy$。例えば $-8=(-2) imes5+2$ なので -8 % 5 == 2。int(-1.6) は0方向への切り捨てで -1、-8 // 5 は床で -2。

2. 位取りと小数の二進表現

基数$b$の位取りでは、各桁に $b^i$ の重みがある。$1011_2=8+2+1=11$、$0.101_2=1/2+1/8=0.625$。

整数部分は2で割った余りを逆順に、小数部分は2倍した結果の整数部分を順に読む。0.625なら $0.625\times2=1.25$、$0.25\times2=0.5$、$0.5\times2=1.0$ より、小数部分は101となる。

有限小数になる条件既約分数 $p/q$ が有限の二進小数となるのは、分母$q$が2のべきの場合。$1/8=0.001_2$ は有限だが、$1/10$ は分母に5を含み、$0.000110011\ldots_2$ と循環する。

3. 符号なし整数と二の補数

$b$ビットの符号なし整数の範囲は $0\leq x\leq2^b-1$。二の補数では最上位ビットの重みを $-2^{b-1}$ とし、範囲は $-2^{b-1}\leq x\leq2^{b-1}-1$。

3の表現011を反転して100、1を足すと101で−3になる。加算は下位$b$ビットを残せばよいが、数学上の答えが表現範囲から外れる場合にはオーバーフローする。

固定幅整数とPythonのintを区別する3ビットの 011 + 001 = 100 は、二の補数では $3+1=-4$ になってしまう。最小値−4の符号反転も100に戻り、+4は表せない。Pythonの int は必要に応じて桁を増やすので、この固定幅の折り返しは起きない。ただし時間とメモリは必要になる。

4. 浮動小数点と整数除算

固定小数点では小数点の位置を固定する。浮動小数点では符号・仮数・指数に分け、広い範囲を表す。通常のPython処理系の float はIEEE 754のbinary64を使う。

形式符号指数格納する小数部正規数の有効精度
単精度 binary321ビット8ビット23ビット先頭の1を含め24ビット
倍精度 binary641ビット11ビット52ビット先頭の1を含め53ビット

正規化されたbinary64の有限値は $(-1)^s(1.f)_2\,2^{E-1023}$。この式は指数部が特殊値用となるゼロ・非正規数・無限大・NaNにはそのまま適用しない。単精度の指数バイアスは127。

例：$43.75=101011.11_2=1.0101111_2\times2^5$。単精度では符号0、指数132（10000100）、小数部0101111の後ろを0で埋める。

10 / 2       # 5.0：割り切れても float
10 // 3      # 3
-10 // 3     # -4：負の無限大方向
int(-10 / 3) # -3：0方向
2 ** 53 + 1  # 9007199254740993：intでは正確
float(2 ** 53) + 1.0 == float(2 ** 53)  # True

Python 3の / は、商が整数かどうかにかかわらず浮動小数点の除算。大きな整数の商が欲しい場合、いったん / でfloatにしてから int に戻す方法は精度を失うことがある。

5. 丸め誤差・情報落ち・桁落ち

種類何が起きるか例
丸め誤差表せる値への近似に伴う誤差0.1を有限の二進小数へ変換する
情報落ち大きな値に対して小さな増分が保持されない1e16 + 1.0 == 1e16
桁落ち近い値の差で有効桁が消え、元の近似誤差が相対的に目立つsqrt(1+x)-1、xが0に近いとき

桁落ちは「引き算の操作が必ず新しい大きな絶対誤差を作る」という意味ではない。入力に含まれた誤差に対して答えが小さくなり、相対誤差が拡大する点が重要である。

有理化で桁落ちを避ける

$$\sqrt{1+x}-1=\frac{x}{\sqrt{1+x}+1}$$
import math

def naive(x):
    return math.sqrt(1 + x) - 1

def stable(x):
    return x / (math.sqrt(1 + x) + 1)

# x=1e-16 では naive は0.0、stable は約5e-17

実数範囲では $x\geq-1$。$x$が十分小さければ値は約$x/2$。表示桁数を増やすだけでは、この式変形の代わりにはならない。

6. 演習2-1〜2-4の解答

2-1：整数と浮動小数点の加算

2**53 + 1 は正確な整数だが、float(2**53) + 1.0 は2**53と同じ値に丸められる。この大きさでは隣接するfloatの間隔が2となり、増分1を保持できない。

2-2：割り算と逆数の掛け算

例えば 7.0 / 8.0 と 7.0 * 0.125 は同じ0.875。逆数1/8は有限の二進小数なので、2のべきによる指数の調整で計算できる。通常の有限値で、オーバーフローやアンダーフローなどを除いた範囲の話である。「どんな値・どんな極端な範囲でも保証」と読み広げない。

2-3：誤差の分類

  1. 7/10 と 7.0*0.1：0.1の表現誤差と演算時の丸め。途中に近似された0.1を掛けるかどうかが違う。
  2. (1e8+1)**2 と展開式：大きな二乗の値に比べて末尾の+1が小さく、保持されない情報落ち。実行環境の通常のbinary64では、どちらも同じ値になる場合がある。設問の「等しくならなかった」を無条件の実行結果として覚えず、実際の値と評価順を確認する。
  3. 1234567890.12345-1234567890.0：大きく近い数の差で有効桁が減り、最初の小数の表現誤差が残る桁落ち。

2-4：複素数の絶対値

import math

def complex_add(a1, b1, a2, b2):
    return a1 + a2, b1 + b2

def complex_abs(a, b):
    return math.sqrt(a * a + b * b)

complex_abs(*complex_add(1e8, 0, 1, 0))  # 100000001.0
complex_abs(*complex_add(1e8, 0, 0, 1))  # 100000000.0

$|10^8+1|$では1が実部に直接加わり、$10^8+1$自体は正確に表せる。一方、$|10^8+i|=\sqrt{10^{16}+1}$ では、二乗和の+1が情報落ちする。また数学的な絶対値の増分自体も約 $5\times10^{-9}$ であり、$10^8$付近のfloatの間隔より小さい。

7. 復習と参考

「どの演算で、どの量が、どの量に比べて小さいのか」を明示すれば、誤差の説明は具体的になる。単に「コンピュータだから誤差が出る」では十分でない。

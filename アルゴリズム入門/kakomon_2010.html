共通試験の解答例と解説。組合せ・出現回数・数値誤差・3方向の格子経路を扱う。問題番号・空欄記号は原本に対応する。2010年度 共通試験問題（出典）を手元で参照しながら読もう。

以下は独自に作成した解答例であり、公式解答ではない。原題のコードはRuby。空欄解答はRubyの記法に合わせ、Pythonで示す実装にはその旨を明記する。当時の科目名は「情報科学」。計算量は、特記がなければ基本演算を定数時間とする問題文のモデルで評価する。

問題1 組合せの表と再帰問題2 種類別の出現回数問題3 丸め誤差と二次方程式問題4 右・上・右上の格子経路

問題1 組合せの表と再帰

(a) イは c[i][i]=1。パスカルの三角形の両端を1で埋める。

(b) 内部への代入(ア)は、(i,j)=(2,1)でc[2][1]=2、(3,1)で3、(3,2)で3の順。i=0,1では内側の範囲に要素がない。

(c) 内部の計算は$\sum_{i=2}^n(i-1)=n(n-1)/2$回で、端点の初期化や表の確保も合わせて$O(n^2)$。

(d) combination(3,2)の呼び出し

C(3,2)
├ C(2,1)
│ ├ C(1,0) → 1
│ └ C(1,1)
│   ├ C(0,0) → 1
│   └ C(0,1) → 0
└ C(2,2)
  ├ C(1,1)
  │ ├ C(0,0) → 1
  │ └ C(0,1) → 0
  └ C(1,2) → 0

左の枝を先に評価し、全体の返値は3。(e) ループ版は対角成分に直接1を代入する。再帰版はC(n−1,n−1)+C(n−1,n)となり、後者0を足しながらC(0,0)=1までたどる。対角成分そのものの専用基底条件は書かれていない。

問題2 種類別の出現回数

(a) n個それぞれに対し、bの最大m要素を線形探索するので最悪 $O(nm)$。配列bの0は、入力が正の整数であることを使った「未使用」の印である。

(b) 整列済みなら同じ値が連続するため、現在の種類の添字を一方向へ進めればよい。以下はRuby版で、n≥1を仮定する。

def intcount(a,b,c)
  j = 0
  b[0] = a[0]
  c[0] = 1
  for i in 1..(a.length-1)
    if a[i] == b[j]
      c[j] = c[j] + 1
    else
      j = j + 1
      b[j] = a[i]
      c[j] = 1
    end
  end
end

各a[i]を1回ずつ処理するので$O(n)$。入力が空の場合は別に何もせず終了する処理を加える。

問題3 丸め誤差と二次方程式

(a) 有限の桁へ近似することで生じる誤差。例は0.1を有限の二進小数に変換する際のずれ。

(b) 0.3==0.1*3 はfalse。近似された0.1を3倍し丸めた値と、0.3を直接近似した値が異なる。

(c) 近い値の差で共通する上位桁が消え、入力の丸め誤差が答えに比べて目立つ桁落ち。例えばxが小さいときの√(1+x)−1。

(d) x²−100x+1=0では、小さい根の分子100−√9996が近い数の差となる。fbは根の積x₁x₂=c/aを使って小さい根を計算し直し、この桁落ちを避ける。checkの値は根を代入した残差であり、改善後のこの実行例では両方0となるが、常に誤差0を保証するものではない。

問題4 右・上・右上の格子経路

(a) (m,n)に最後に到達する移動元は(m,n−1),(m−1,n),(m−1,n−1)の3種類。互いに最後の移動が違うため重複せず、

$$T_{m,n}=T_{m,n-1}+T_{m-1,n}+T_{m-1,n-1}.$$

境界では一直線に進む方法しかないので、$T_{0,0}=T_{0,i}=T_{j,0}=1$。

(b) 左端・下端を1で埋め、内部を既に分かっている3セルの和で埋める。以下はPython版。

def routes(M, N):
    count = [[1] * (M + 1) for _ in range(N + 1)]
    for y in range(1, N + 1):
        for x in range(1, M + 1):
            count[y][x] = (count[y - 1][x]
                           + count[y][x - 1]
                           + count[y - 1][x - 1])
    return count[N][M]

時間と領域は $O((M+1)(N+1))$。各行を独立に確保し、同じ行を複数参照する2次元配列を作らないようにする。

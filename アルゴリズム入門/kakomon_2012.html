問題1 再帰と反復

(a) f(5)=5!=120。(b) 再帰を反復へ直すには、1からnまでの積を累積する。

def factorial(n):
    result = 1
    for i in range(2, n + 1):
        result = result * i
    return result

上はPython版で、nは非負整数とする。(c) gの初期値はg(0)=g(1)=1なので、g(2)=2,g(3)=3,g(4)=5,g(5)=8。通常のF₀=0,F₁=1という添字付けと混同しない。

問題2 2要素間の最小差

(a) 全てのi<jの組で|a[i]−a[j]|を計算し、最小値を更新する。組数はn(n−1)/2なので$O(n²)$。

(b) 整列済みなら隣接するn−1組だけでよい。離れた2要素の間に別の要素があれば、その2要素の差より大きくない隣接差があるためである。時間$O(n)$。

(c) 併合整列などの$O(n\log n)$の方法で整列してから隣接差を調べる。全体は$O(n\log n)$となる。

def minimum_gap(a):
    ordered = sorted(a)
    answer = ordered[1] - ordered[0]
    for i in range(1, len(ordered)):
        answer = min(answer, ordered[i] - ordered[i - 1])
    return answer

Python版。n≥2を前提とし、同じ値があれば答えは0。元配列を保持するためコピーして整列する。

問題3 ピボットと不能・不定

(a) アは 1.0 / akk、イは aik * a[k][j]。ピボット行を規格化してから、他行の同じ列を消去する。

(b) 二進で表せない商の丸めが後の演算へ伝わる。小さいピボットで割ると誤差が増幅し、近い値の差では桁落ちも起こる。

(c) akkを読む直前に swap(a,k,maxrow(a,k)) を加える。対象列で絶対値最大の行を選ぶ部分ピボット選択で、ゼロや微小な値で割ることを避ける。

(d) 行交換後にピボットa[k][k]が0なら、その列の残り全てが0で、正方の係数行列は階数不足。唯一の解はなく、不能または不定なので割り算前にabortする。

# 原題のRuby：akk = a[k][k] の前
swap(a,k,maxrow(a,k))
if a[k][k] == 0
  abort()
end

「不能」と「不定」のどちらかまで区別するなら、残りの列を含む消去と、係数が全て0で右辺だけ非零の行の有無を調べる。float実装ではゼロの判定に許容誤差やスケールも考慮する。

問題4 文字列対応問題と探索の限界

(a) 添字列の一例は [1,0,0,2,2]。a側は0+1+1+00+00、b側は011+0+0+0+0で、どちらも 0110000。

(b) k=0の追加では一致せず、k=1を追加したときに "11011" 同士で一致するので、返値は "11011"。

(c) 例えば post(["1","0","00"],["0","011","0"],3,5,"","") と呼ぶと、深さ5までで見つかる "0110000" を返す。第4引数は「追加できる選択回数の上限」であり、解の存在を調べるには十分な深さを与える必要がある。

(d) 解がないと深さnまでm分岐を全探索する。$1+m+\cdots+m^n$ なので、m≥2なら $\boxed{O(m^n)}$。m=1なら$O(n)$。文字列処理を定数時間とする問題文の仮定による。

考え方有限の深さまで探して見つからなかったことは、長さ制限のない解が存在しないことの証明ではない。停止問題と同様、探索が終わることと、無制限の問題を完全に判定することを区別しよう。

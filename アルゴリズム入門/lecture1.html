1. ディジタル情報とビット

コンピュータで扱うには、対象を記号や数値で表す必要がある。重さや時間のような連続量を有限の刻みで表せば、区別できる値は離散的になる。記録や伝送は容易になる一方、刻みより細かい情報は失われる。

ビット列と場合の数1ビットは2通りの区別を表す。$b$ビットなら $2^b$ 通り。$M$種類を区別するために必要な最小ビット数は $\lceil\log_2 M\rceil$（$M\geq1$）。

天気を晴・曇・雨・雪の4種類に分けるなら2ビットで足りる。曜日7種類なら3ビットが必要で、8通りのうち1通りは未使用になる。「ビット列」は値そのものではなく、解釈の規則と組になって意味を持つ。

2. モデル化・抽象化・アルゴリズム

三角形の面積を計算するとき、紙に描いた線の太さや色は不要で、底辺と高さを取り出せばよい。必要な側面を取り出したものがモデル、不要な側面を捨てる操作が抽象化である。

アルゴリズム入力と出力、各操作の意味が明確な、有限の記述による問題解決手順。この講義では対象とする入力に対して停止することも条件に含める。プログラムはその手順をコンピュータが実行できる言語で記述したもの。

決定性・正しさ・停止性は別の観点。同じ入力から同じ結果が出るだけでは、正しいとは限らない。「常に0を返す」手順も決定的だが、面積計算としては一般に誤りである。ここでは決定的な手順を中心に扱うが、広い意味では乱数を使うアルゴリズムもある。

停止問題の考え方を見る

あらゆるプログラム $A$ と入力 $x$ の停止を、必ず有限時間で正しく判定する $H(A,x)$ があると仮定する。$H(A,A)$ が「停止する」と判定したら無限ループし、「停止しない」と判定したら終了するプログラム $S(A)$ を作る。$S(S)$ はどちらの判定でも矛盾する。

これは万能な停止判定器が存在しないという主張であり、個々の単純なプログラムについて停止性を証明できないという意味ではない。

3. 変数と代入は状態を変える

変数は値を保持する場所を抽象化したもの。代入は右辺を現在の状態で評価し、その結果を左辺の変数に結び付ける操作である。数学の等式と異なり、実行順序が意味を持つ。

x = 3
x = x + 2  # 古い x=3 を読んで、x を5に更新する
y = x * 4  # y は20になる

擬似コードでは代入を $x\leftarrow x+2$ と書く。Pythonの = は代入、== は等しいかを調べる比較。演算と代入で状態を変えて計算を進める考え方を、手続き型計算モデルという。

4. Pythonの関数・引数・戻り値

def triangle_area(width, height):
    area = width * height / 2
    return area

triangle_area(8, 5)  # 20.0
triangle_area(7, 3)  # 10.5

def は関数の定義、括弧の中の名前は仮引数、呼び出し時に渡す具体的な値は実引数。コロンに続く字下げされた部分が本体となる。return は文であり、結果を呼び出し元へ返して、その関数呼び出しを終える。

print は画面に表示する。表示しただけでは、その値が関数の戻り値になるわけではない。return を通らず終了すると None が返る。

関数は標準テキストの .py に保存し、IDLEのファイルを開く操作と「Run Module」で読み込んでから呼び出せる。ファイルを修正したら再実行する。インデントを揃え、引用符や記号はコード内で半角を使う。

5. 演習1-1〜1-3の解答と確認

1-1・1-2：入力の型と割り算

数値の 8, 5 と、文字列の "8", "5" は異なる。文字列同士を掛けると TypeError。文字列と整数の積は文字列の反復になるが、その後の除算はできない。入力の型まで確認しよう。

Python 3では 8 * 5 / 2 も 8 * 5 / 2.0 も 20.0。/ は整数同士でも浮動小数点の除算となる。整数商を求める // とは区別する。

1-3a：四則演算

def arithmetic(x, y):
    return x + y, x - y, x * y, x / y

s, d, p, q = arithmetic(5, 2)  # 7, 3, 10, 2.5
# y=0 の除算は ZeroDivisionError

表示する指定なら、各計算結果を print する。再利用するなら上のようにタプルで返すとよい。

1-3b：剰余

def remainder(x, y):
    return x % y

# 8%5=3, -8%5=2, 8%-5=-2, -8%-5=-3

Pythonの整数では、$x=(x//y)y+(x\%y)$。剰余は0、または除数と同符号になる。負数での挙動は言語によるので、経験だけで決め付けない。

1-3c：円錐の体積

import math

def cone_volume(radius, height):
    return math.pi * radius ** 2 * height / 3

cone_volume(3, 4)  # 約37.6991

式は $V=\pi r^2h/3$。** がべき乗であり、^ ではない。物理的な円錐として使うなら半径と高さは非負とする。

1-3d：表示桁数を増やして比較する

def compare(x):
    print("%.20g" % (x / 10.0))
    print("%.20g" % (x * 0.1))

compare(7)
# 0.69999999999999995559
# 0.70000000000000006661

数学的に等しい式でも、途中の二進近似と丸めによって結果が違う。表示桁数を増やしても計算精度は増えない。この理由を第2回で詳しく扱う。

6. 表示形式と復習

書式意味例
%.10g有効数字10桁小さい数・大きい数は指数表示になる場合がある
%.10f小数点以下10桁1/3 → 0.3333333333
%.10e小数点以下10桁の指数形式1/3 → 3.3333333333e-01
%d整数の十進表記整数を表示する

書式の % と、整数の余りを取る % は文脈が異なる。%.Nf や %.Ne のNを「有効数字の桁数」と混同しない。

自分で説明する：8種類を区別するには何ビットか。代入と等式はどう違うか。print と return の役割は何か。

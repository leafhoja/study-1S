# アルゴリズム入門 — 1A

- 学習ノートサイトの科目ページ。親の AGENTS.md に従う。
- 担当：地引昌弘。学期は **1A**。S・1S と記載しない。
- 実施済みの講義は第1・2回。講義資料は参考資料/r1.pdf（2026-10-08）、r2.pdf（2026-10-15）の2回分のみ。第3回以降は今後の講義実施に合わせて追加する。講義前の内容を推測で追加しない。
- lecture1.html / lecture2.html は講義解説。講義内の演習も解説する。
- 共通試験2010〜2025年度は kakomon_YYYY.html。年度と実際の試験実施年を混同しない。
- 2010〜2014年度の原題は「情報科学」、2010〜2017年度のコードはRuby。現行Pythonとの整数除算・真偽値・範囲指定の差を明記する。
- 過去問解答は独自の解答例であり公式解答と表記しない。原本への出典リンクは公開元URLを使う。
- 原本PDFと出典メモのある参考資料/は親 .gitignore で除外。HTMLからローカル原本にリンクしない。
- 共通デザイン、検索、ページ単位のアクセス制御を維持。本文更新後は tools/build-search-index.py アルゴリズム入門 を実行。

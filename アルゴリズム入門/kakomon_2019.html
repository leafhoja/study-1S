問題1 インデント・return・配列の反転

(1) x>0かつy≤0の場合にreturnへ達せずNoneとなる。仕様通り−1を返すようにする。

def func1(x, y):
    if y <= 0:
        return -1
    if x > 0:
        return 0
    return 1

(2) 元のfunc2のreturnは外側forの内部なので、1行目の最大値しか調べない。最大値が後続行にしかない入力で誤る。return m を外側forの外へ出す。dataと各参照行が空でないことを仮定する。

(3a) rev1はi=0で a[len(a)] を参照し、範囲外の IndexError。(3b) rev2([1,2,3,4,5,6,7])は [7,6,5,4,5,6,7]。元の左半分を上書きしてから読むためである。

(2) k行目以降で対象列の絶対値が最大の行を選んで交換する部分ピボット選択。ゼロや小さいピボットで割ることを避ける。

(3・最初の問) c=2では3をピボットとして2/3や5/3などの有限二進数にならない値を計算する。表現と演算の丸めが伝わり、末尾に小さな誤差が出る。離散化に由来する打切り誤差ではない。

(3・後の問) c=2⁵³ではfloatの c+1 がcへ丸められ、2*c+1 も末尾の1を失う。異なるはずの2式が同じ係数を持ち、消去後にゼロのピボットが生じる。最初のデータ構築時点の情報落ちは、ピボット選択では復元できない。

問題3 経路の再帰とモンテカルロ法

空欄解答

(1) 最後の移動が上からか左からかで分ける。経路数は $\binom{20}{10}=184756$。

(2) 同じ座標の値を何度も再計算し、中央への経路数自体が指数的に増える。n,nの場合は多項式n,n²,n³,n⁴のいずれでもなく、指数時間。メモ化すれば状態は(n+1)²個となる。

(3a) 20回のうち下方向に10回進めば右方向も10回なので、i==10 が成功条件。(3b) 推定値は $(17550/100000)\times(1.05\times10^6)=184275$、有効数字3桁で $\boxed{1.84\times10^5}$。

(4) 障害物がある場合

(a) 2番目の elif を if に変える。どちらも通行可能なら両方の寄与を足さなければならない。(b) 原図の黒マスは(1,1),(3,3),(5,5),(7,7),(9,9)。

def is_available(i, j):
    return (i >= 0 and j >= 0
            and not (i == j and i % 2 == 1))

この関数は到着先から左・上へ戻って調べる原題の呼び方を前提とする。盤外も自由に呼ぶ汎用関数なら上限i,j≤10も加える。

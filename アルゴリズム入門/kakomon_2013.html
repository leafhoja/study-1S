2013年度 過去問解説

併合整列・重複再帰・複素Newton法・確率の動的計画法

1A · 共通試験 · 年度は原本の表題に準拠

共通試験の解答例と解説。併合整列・重複再帰・複素Newton法・確率の動的計画法を扱う。問題番号・空欄記号は原本に対応する。2013年度 共通試験問題（出典）を手元で参照しながら読もう。

以下は独自に作成した解答例であり、公式解答ではない。原題のコードはRuby。空欄解答はRubyの記法に合わせ、Pythonで示す実装にはその旨を明記する。当時の科目名は「情報科学」。計算量は、特記がなければ基本演算を定数時間とする問題文のモデルで評価する。

第1問 下から併合する整列

空欄解答（Ruby）
アfrom[n-1]
イ(n+1) / 2
ウfrom[0]

(a) 本数が奇数なら最後の配列をそのまま次段へ送る。Rubyの整数除算で(n+1)/2は本数の切り上げ半分となる。

(b) whileの条件(エ)を評価するたびのfromは次の4段階（最後はn=1で終了）。

[[7],[2],[8],[3],[1],[4],[6],[5]]
[[2,7],[3,8],[1,4],[5,6]]
[[2,3,7,8],[1,4,5,6]]
[[1,2,3,4,5,6,7,8]]

(c) 単純整列は$O(n^2)$時間、追加メモリ$O(1)$で実装できる。併合整列は$O(n\log n)$時間で、配列を複製するこの方式では追加メモリ$O(n)$を使う。段ごとに不要な旧配列を保持しないものとする。

第2問 一度の走査と重複再帰

(a) 隣接比較の1回走査

(オ)でのia
1[1,3,2,5,4]
2[1,2,3,5,4]
3[1,2,3,5,4]
4[1,2,3,4,5]

この例は整列するが、一般には1回の走査では足りない。反例は[3,2,1]で、返値は[2,1,3]。最大値が右端へ移るだけで、残りまで整列したとは限らない。

(b) 同じ再帰呼び出しを2回しない

(i) 例えば昇順の[1,2,3,4]では毎回elseとなり、min(a,i,j−1)が2回ずつ呼ばれる。$C(1)=1,C(n)=1+2C(n-1)$より $C(n)=2^n-1$、時間は$\Theta(2^n)$。

(ii) 再帰で求めた値を変数に保存し、比較と返値で再利用する。

def recursive_min(a, i, j):
    if i == j:
        return a[i]
    previous = recursive_min(a, i, j - 1)
    return a[j] if a[j] < previous else previous

これはPython版。呼び出しは1段1回となり、時間$O(n)$、スタック$O(n)$。

第3問 複素数とNewton法

(a) 除算（Ruby）

def div(x, y)
  den = y[0]*y[0] + y[1]*y[1]
  [(x[0]*y[0] + x[1]*y[1])*1.0/den,
   (x[1]*y[0] - x[0]*y[1])*1.0/den]
end

分母はyの絶対値の二乗。y≠0を仮定し、整数入力でも実数の除算にする。

(b) 実部に1を足す場合は10⁸+1自体を正確に表せる。一方、虚部に1を足した絶対値は√(10¹⁶+1)となり、二乗和で+1が情報落ちし、元の10⁸と同じ値になる。

(c) fと導関数（Ruby）

def f(x)
  plus(plus(mul(x,x),x),[1.0,0.0])
end

def fd(x)
  plus(mul([2.0,0.0],x),[1.0,0.0])
end

(d) カは plus(x, mul([-1.0,0.0], div(f(x), fd(x))))。更新式は $x\leftarrow x-f(x)/f'(x)$。f′(x)=0での除算や非収束の可能性があるため、実用版では初期値・反復上限も検討する。停止した場合の残差を指定値未満にする原題の条件と、全初期値で必ず停止するという主張は別である。

第4問 勝敗引分の状態と確率

(a) 負の添字の状態を0、初期状態(0,0,0)を1とする。その他では最後の試合の直前の状態から確率を流入させる。

$$P(i,j,k)=P(i-1,j,k)w(i-1,j,k)+P(i,j-1,k)l(i,j-1,k)+P(i,j,k-1)d(i,j,k-1).$$

添字が負になる項は0として除外する。勝率等は到着先ではなく直前の状態で評価する。

(b) 単純再帰では同じ(i,j,k)を多数の経路から求めるため、試合数に応じて呼び出しが急増する。

(c) キは 1.0。クは上式のPを配列参照に置き換えたもの：

value(a,x-1,y,z)*w(x-1,y,z) +
value(a,x,y-1,z)*l(x,y-1,z) +
value(a,x,y,z-1)*d(x,y,z-1)

率の関数が非負の状態だけで定義される場合、x>0,y>0,z>0をそれぞれ確認してから対応する項を加える必要がある。0を掛ける式でもRubyはその関数を評価するためである。表の走査順は依存する小さい座標を先に計算する。状態数は$O(n^3)$、各状態は定数時間なので、時間・表の領域とも$O(n^3)$。

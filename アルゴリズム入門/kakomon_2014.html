2014年度 過去問解説

再帰による行列演算・到達確率・数値誤差・順序付き割り当て

1A · 共通試験 · 年度は原本の表題に準拠

共通試験の解答例と解説。再帰による行列演算・到達確率・数値誤差・順序付き割り当てを扱う。問題番号・空欄記号は原本に対応する。2014年度 共通試験問題（出典）を手元で参照しながら読もう。

以下は独自に作成した解答例であり、公式解答ではない。原題のコードはRuby。空欄解答はRubyの記法に合わせ、Pythonで示す実装にはその旨を明記する。当時の科目名は「情報科学」。計算量は、特記がなければ基本演算を定数時間とする問題文のモデルで評価する。

問題1 ベクトルと行列の再帰

空欄解答（Ruby）
Aa.length == 0
B・C1..(a.length-1) ・ 1..(b.length-1)
Da[0] + b[0]
Ea.length == 0
Finner(v, a[0])
G1..(a.length-1)
Ha.length == 0
Ivmmult1(a[0], b)
J1..(a.length-1)

(1) 先頭要素を計算し、残りの部分配列に同じ関数を再帰適用する。内積の空列は0、ベクトル和の空列は[]。

(2) vmmultは行ベクトルvと行列aの積。aを転置しておけば、各行とvの内積が出力の各成分になる。

(3) mmmult1に渡されたbは既に転置済みである。Iにはvmmultではなくvmmult1を使うと、余計な転置を避けられる。各aの行について、全てのbの列との内積を計算する。

問題2 停止したゲームからは流入しない

(1) 初期条件はP(0,5)=1、その他0。t≥1では、

$$P(t,a)=\begin{cases}qP(t-1,a+1)&a=0,1,\\pP(t-1,a-1)&a=9,10,\\pP(t-1,a-1)+qP(t-1,a+1)&2\leq a\leq8.\end{cases}$$

0枚と10枚では以降のゲームを行わないため、そこから1枚・9枚へ流入させない。P(t,0)等は累積確率ではなく、ちょうどt回目にそこへ到達した確率である。

空欄解答（Ruby）
A0
Bq * prob[i-1][j+1]
Cp * prob[i-1][j-1]
Dp*prob[i-1][j-1] + q*prob[i-1][j+1]
Eprob[t][a]

(2) 単純再帰は同じ時刻・所持金の状態を何度も計算するので、呼び出し数が急増する。(3) 既に計算した直前時刻の表を参照すればよい。(4) 上限n枚なら時刻tと金額nの2重ループで$O(tn)$、表全体の領域も$O(tn)$。直前時刻だけ保持すれば領域$O(n)$にもできる。

(5) 計算量のオーダーは、入力が大きくなったときの資源消費の増え方を、定数係数や低次項を省いて比較する指標。環境に依存する実行時間そのものより、規模を増したときの差を見通しやすい。

問題3 数値誤差と面積比

(1) a=1000はRubyの整数なので1/a=0。Python 3の除算とは違う。(2) a=1000.0なら逆数や1への加算の丸めがあり、近い値の引き算後に誤差が表れる。(3) 1/a⁵は小さく、1へ加えた際に残せる相対精度が低下する。差を取ってa⁵倍すると誤差が目立つ。(4) 1/a⁶は1への加算で完全に失われ、結果0となる。

(5) A= 1.0。2⁻⁴⁰は1に加えた結果も正確に表せる。(6) B= 0.0。2⁻⁶⁰は1へ加えると失われる。

(7) x=0.4,y=0.2では原点からの距離だけが0.5未満、残り3頂点からは0.5超なので、calc(1)は3.0。

(8) 各頂点の半径0.5の四半円の面積はπ/16。1点がその外にある確率は1−π/16で、4条件の指示変数の期待値の和は $\boxed{4-\pi/4}$。同じ点に対する4条件を独立と仮定する必要はなく、期待値の線形性で計算できる。

問題4 順序を保った盗賊と捜査官の割り当て

空欄解答（Ruby）
AC[i][0]
Bi + 1
CC[j][1]
Dmax
Ercvr[n-1][m-1] + C[n-1][m-1]

(1) 捜査官0を盗賊iに付けたら、捜査官1は必ずj>iの盗賊に付ける。(2) 捜査官3人なら3個の添字の組を列挙するので$O(N^3)$。

(3) 末尾の盗賊を担当させない場合と、最後の捜査官に担当させる場合の大きい方。後者では、残りの先頭n−1人に先頭m−1人を最適に配置する。

(4) 表を埋める実装（原題のRuby）

for n in 0..N
  for m in 0..M
    if m == 0 || n == 0 || m > n
      rcvr[n][m] = 0
    else
      rcvr[n][m] = [rcvr[n-1][m],
                    rcvr[n-1][m-1] + C[n-1][m-1]].max
    end
  end
end

回収額が正という原題の前提の下で、必要な人数全員を配置する値が得られる。負の回収額も許す一般化では、不可能な状態を0で初期化すると誤るので−∞などで区別する。計算量は$O(NM)$。

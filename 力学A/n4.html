第4章　万有引力とケプラーの法則

軌道方程式の導出・円錐曲線・エネルギーによる軌道の分類

講義ノート §6 にもとづく（「今回後半が重要」との書き込みあり）

この章について
万有引力のもとで運動する質点（惑星）の軌道が，なぜ楕円（あるいは放物線・双曲線）になるのかを， 第2・3章で準備した「保存力・ポテンシャル」「極座標での運動方程式」を武器にして導出する。 ケプラーの３法則すべてが，たった１つの運動方程式から導かれることを見る。
1. 万有引力とケプラーの3法則 2. 運動方程式（第2法則） 3. 軌道の方程式（第1法則） 4. 周期（第3法則） 5. エネルギーによる軌道の分類 6. 円軌道近傍の微小振動
Section 1

万有引力とケプラーの3法則

万有引力の法則

質量 $m$ の質点と質量 $M$ の質点（距離 $r$）の間には，引力

$$|\mathbb F| = G\frac{mM}{r^2}$$

がはたらく（$G$：万有引力定数）。これは第2章の意味で中心力であり，したがって保存力である。

ケプラーの3法則
  1. 惑星の軌道は，太陽を１つの焦点とする楕円である。
  2. 面積速度（単位時間に動径が掃く面積）は一定である。
  3. 公転周期の２乗は，軌道の長半径の３乗に比例する：$(\text{周期})^2\propto(\text{長半径})^3$。

惑星の位置を，太陽を原点とする極座標 $(r,\varphi,z)$（$xy$平面内の運動として $z$ 方向は考えなくてよい） で表す。第3章の極座標での運動方程式を使うと：

$$\begin{cases} m(\ddot r - r\dot\varphi^2) = -\dfrac{GmM}{r^2} & (r\text{方向})\\[6pt] m(2\dot r\dot\varphi + r\ddot\varphi) = 0 & (\varphi\text{方向})\\[4pt] m\ddot z = 0 & \Rightarrow z\text{方向は考慮しなくてよい} \end{cases}$$
Section 2

第2法則：面積速度一定

$\varphi$方向の式 $2\dot r\dot\varphi+r\ddot\varphi=0$ の両辺を $r$ で割ると：

$$\frac1r\frac{d}{dt}(r^2\dot\varphi) = 0 \quad\Longrightarrow\quad r^2\dot\varphi = h\ (\text{一定})$$

図形的には，微小時間 $dt$ の間に動径ベクトルが掃く面積は $dS=\frac12 r\cdot r\,d\varphi=\frac12r^2\dot\varphi\,dt$ なので，面積速度 $\dfrac{dS}{dt}=\dfrac12 r^2\dot\varphi=\dfrac h2$ は一定 —— これがケプラーの第2法則である。 （$h$ は，質量で割った角運動量 $mr^2\dot\varphi$ に等しい。）

Section 3

第1法則：軌道の方程式（楕円軌道の導出）

万有引力は保存力であり，そのポテンシャルは $U(r)=-\dfrac{GmM}{r}$（第2章の定義に基づいて計算できる）。 力学的エネルギー保存則：

$$\frac12m\left(\dot r^2+(r\dot\varphi)^2\right) - \frac{GmM}{r} = E \quad\cdots(0)$$

第2法則 $r^2\dot\varphi=h$（一定）$\cdots(1)$ を使って $\dot\varphi=h/r^2$ を(0)に代入すると：

$$\frac12m\dot r^2 + \frac{mh^2}{2r^2} - \frac{GmM}{r} = E \quad\cdots(2)$$
導出：軌道の方程式 $r=r(\varphi)$ を求める

(1)から $\dot\varphi^2=h^2/r^4$，(2)から $\dot r^2 = \dfrac{2E}m+\dfrac{2GM}r-\dfrac{h^2}{r^2}$ が出るので，比をとると：

$$\left(\frac{dr}{d\varphi}\right)^2 = \frac{\dot r^2}{\dot\varphi^2} = \frac{r^4}{h^2}\left(\frac{2E}m+\frac{2GM}r-\frac{h^2}{r^2}\right)$$

ここで $u\equiv 1/r$ という変数に置き換える（$\dfrac{du}{d\varphi}=-\dfrac1{r^2}\dfrac{dr}{d\varphi}$ に注意）：

$$\left(\frac{du}{d\varphi}\right)^2 \equiv u'^2 = \frac{2E}{mh^2} + \frac{2GM}{h^2}u - u^2$$

両辺を $\varphi$ でもう一度微分すると（$u'\ne0$ として両辺を $2u'$ で割る）：

$$2u'u'' = \frac{2GM}{h^2}u' - 2uu' \quad\Longrightarrow\quad u'' + u = \frac{GM}{h^2} \equiv \frac1\ell$$

（$\ell\equiv h^2/(GM)$ とおいた。）これは第1章でみた「２階線形非斉次微分方程式」であり， 斉次解は $\cos\varphi,\sin\varphi$，特解は定数 $1/\ell$ だから，一般解は：

$$u = A\cos(\varphi+\alpha) + \frac1\ell$$

これを $u'^2=\frac{2E}{mh^2}+\frac{2GM}{h^2}u-u^2$ に戻して代入すると（$\psi\equiv\varphi+\alpha$ とおき， $GM/h^2=1/\ell$ に注意すれば），$\psi$ に依存する項がすべて消えて：

$$A^2 = \frac{2E}{mh^2}+\frac1{\ell^2} \quad\Longrightarrow\quad A = \sqrt{\frac{2E}{mh^2}+\frac1{\ell^2}}$$
∎
軌道の方程式 $$\boxed{r = \frac{\ell}{1+e\cos(\varphi+\alpha)}}, \qquad \ell = \frac{h^2}{GM},\quad e\equiv \ell A = \ell\sqrt{\frac{2E}{mh^2}+\frac1{\ell^2}}$$

これは，離心率 $e$ の円錐曲線の極座標表示に他ならない（$0\le e<1$ で楕円，$e=1$ で放物線， $e>1$ で双曲線 —— §5 で詳しく分類する）。すなわち，惑星（束縛された天体）の軌道はケプラーの第1法則の通り， 太陽を焦点の１つとする楕円になる。長半径・短半径は：

$$(\text{長半径}) = \frac{\ell}{1-e^2}, \qquad (\text{短半径}) = \frac{\ell}{\sqrt{1-e^2}}$$
Section 4

第3法則：周期

面積速度 $\dfrac{dS}{dt}=\dfrac12 r^2\dot\varphi = \dfrac h2$（一定）なので，１周期 $T$ の間に掃く全面積は：

$$S = \int_0^T \frac h2\,dt = \frac{hT}{2}$$

一方，楕円の面積は $S=\pi\times(\text{長半径})\times(\text{短半径}) = \pi\cdot\dfrac{\ell}{1-e^2}\cdot\dfrac{\ell}{\sqrt{1-e^2}}=\dfrac{\pi\ell^2}{(1-e^2)^{3/2}}$。よって：

$$T = \frac{2S}{h} = \frac{2\pi\ell^2}{h(1-e^2)^{3/2}}$$

$\ell=h^2/(GM)$，すなわち $h=\sqrt{GM\ell}$ を代入して整理すると：

$$T = \frac{2\pi}{\sqrt{GM}}\left(\frac{\ell}{1-e^2}\right)^{3/2} = \frac{2\pi}{\sqrt{GM}}\,(\text{長半径})^{3/2}$$
結論 $T^2 = \dfrac{4\pi^2}{GM}(\text{長半径})^3$ —— これがケプラーの第3法則である。比例定数 $4\pi^2/(GM)$ は （太陽の場合）中心天体の質量 $M$ だけで決まり，惑星の質量 $m$ にはよらない。
Section 5

運動エネルギーと軌道の分類（重要）

(2)式 $\frac12m\dot r^2 + \dfrac{mh^2}{2r^2} - \dfrac{GmM}{r} = E$ は，「$r$ 方向の１次元運動」として読み直せる：

$$\underbrace{\frac12m\dot r^2}_{\text{運動エネルギー}} + \underbrace{U_r(r)}_{\text{有効ポテンシャル}} = E, \qquad U_r(r) \equiv -\frac{GmM}{r}+\frac{mh^2}{2r^2} = U(r)+U_{\rm cen}(r)$$

$U(r)=-GmM/r$ は万有引力本来のポテンシャル，$U_{\rm cen}(r)=mh^2/(2r^2)$ は「遠心力のポテンシャル」 （角運動量を固定して動径方向だけ見たときに現れる，遠心力に対応する項）である。$r\to0$ では $1/r^2$ の $U_{\rm cen}$ の方が $1/r$ の $U(r)$ よりも急激に発散するため支配的（斥力的）になり，$U_r(r)$ 全体としては ある有限の $r=\ell$ で最小値をとる「井戸型」のグラフになる（右図イメージ：質点はこの井戸の中を転がる）。

$E$ の下限と軌道の分類

$\dot r^2 = \dfrac{2E}m+\dfrac{2GM}r-\dfrac{h^2}{r^2}\ge0$ でなければならない（実数の速度である以上）。 $u=1/r$ とおくと，$r>0$ の解が存在する条件は $u>0$ の解が存在する条件と同じで：

$$\frac{2E}m+2GMu-h^2u^2 \ge 0\ \text{を満たす}\ u>0\ \text{が存在}$$

左辺は $u$ の（上に凸な）２次式だから，実根を持つ条件 $0\le \dfrac D4=G^2M^2+\dfrac{2Eh^2}m$ より：

$$\boxed{E \ge -\frac{G^2M^2m}{2h^2}} \equiv E_{\min}$$

§3 で求めた $x=r\cos(\varphi+\alpha)$，$y=r\sin(\varphi+\alpha)$ とおいて軌道の方程式を直交座標に書き直すと， （計算を進めると）$y^2=(e^2-1)x^2-2e\ell x+\ell^2$ という円錐曲線の一般形が得られる。これにより：

離心率 $e=\ell A$エネルギー軌道の形
$0\le e<1$$E_{\min}\le E<0$楕円（$e=0$ は円，$E=E_{\min}$）
$e=1$$E=0$放物線
$e\ge1$$E>0$双曲線
補足

$E<0$（束縛状態，$r\to\infty$ には行けない）なら楕円軌道＝惑星のような周期運動。 $E\ge0$（非束縛，$r\to\infty$ まで到達できる）なら放物線・双曲線軌道＝彗星の１回限りの通過などに対応する。

Section 6

円軌道近傍の微小振動

$E=E_{\min}$ のとき軌道は半径 $r=\ell$ の円軌道になる（$U_r'(\ell)=0$，すなわち有効ポテンシャルの底）。 ここで，円軌道からわずかにずれた（ほぼ円に近い楕円の）場合の $r$ 方向の微小振動の周期を， 円運動そのものの周期と比較してみる。

導出

有効ポテンシャル $U_r(r)=\dfrac{mh^2}{2r^2}-\dfrac{GMm}{r}$ を最小にする $r$ を求める：

$$\frac{dU_r}{dr} = -\frac{mh^2}{r^3}+\frac{GMm}{r^2} = 0 \quad\Longrightarrow\quad r=\frac{h^2}{GM}=\ell \quad(U_r'(\ell)=0)$$

$U_r(\ell) = -\dfrac{G^2M^2m}{2h^2} = E_{\min}$ となることも確認できる。$r=\ell$ のまわりでテイラー展開すると：

$$U_r(r) = U_r(\ell) + \frac12 U_r''(\ell)(r-\ell)^2+\cdots$$

（１次の項は $U_r'(\ell)=0$ より消える。）$U_r''(r) = \dfrac{3mh^2}{r^4}-\dfrac{2GMm}{r^3}$ に $r=\ell$ を代入すると：

$$U_r''(\ell) = \frac{G^4M^4m}{h^6} \equiv \kappa$$

これは，質量 $m$ のばね定数 $\kappa$ の単振動（第1章 §2 の調和振動子）とまったく同じ形。よって微小振動の周期は：

$$T_{\rm osc} = 2\pi\sqrt{\frac{m}{\kappa}} = 2\pi\,\frac{h^3}{G^2M^2}$$

一方，円運動そのものの周期は $\dot\varphi = h/\ell^2$ より：

$$T_{\rm circ} = \frac{2\pi}{\dot\varphi} = \frac{2\pi \ell^2}{h} = 2\pi\,\frac{h^3}{G^2M^2}$$
∎
結論 $T_{\rm osc}=T_{\rm circ}$。動径方向の微小振動の周期は，円運動そのものの周期にちょうど一致する。
見通し — 近日点は動かない（逆２乗力の特別な性質）

この一致は，逆２乗則の万有引力に特有の性質である。もし力の距離依存性が $1/r^2$ からわずかにずれると （例えば一般相対論的な補正項が加わると），この２つの周期は一致しなくなり，楕円軌道の近日点（最も 太陽に近づく点）が公転ごとに少しずつ回転する「近日点移動」が生じる。水星の近日点移動が観測され， 一般相対論の重要な検証例になったことは有名である。

Setup

設定

この節の目標

$n$ を正整数，$V$ を $\mathbb{K}$-ベクトル空間とする。 $T:\mathbb{K}^n\to V$ という $\mathbb{K}$-線形写像の構造を明らかにする。

鍵となる問い：$T:\mathbb{K}^n\to V$ を決めるには何を指定すればよいか？

$e_1,\ldots,e_n$ を $\mathbb{K}^n$ の基本単位ベクトルとする： $$e_i = \begin{pmatrix}0\\\vdots\\0\\1\\0\\\vdots\\0\end{pmatrix} \leftarrow i\text{ 番目}$$ 任意の $x = (x_1,\ldots,x_n)^\top\in\mathbb{K}^n$ は $$x = x_1e_1 + x_2e_2 + \cdots + x_ne_n$$ と一意に表せる。$T$ が線形写像ならば $$T(x) = x_1T(e_1) + x_2T(e_2) + \cdots + x_nT(e_n)$$ となる（線形性 (L1)(L2) の反復適用）。よって $T$ の値は $T(e_1),\ldots,T(e_n)$ だけで完全に決まる。

Lemma 5.1

補題 5.1 — 行き先 $v_1,\ldots,v_n$ による $T$ の決定

補題 5.1 $v_1,\ldots,v_n\in V$ とする。写像 $T_{v_1,\ldots,v_n}:\mathbb{K}^n\to V$ を $$T_{v_1,\ldots,v_n}\!\begin{pmatrix}x_1\\\vdots\\x_n\end{pmatrix} = x_1v_1 + x_2v_2 + \cdots + x_nv_n$$ で定める。すると：
  1. $T_{v_1,\ldots,v_n}$ は $T_{v_1,\ldots,v_n}(e_i)=v_i\ (1\le i\le n)$ をみたす $\mathbb{K}$-線形写像である。
  2. 逆に $T:\mathbb{K}^n\to V$ を任意の $\mathbb{K}$-線形写像とすると， $$T_{T(e_1),\ldots,T(e_n)} = T$$ が成り立つ。
補題 5.1 の意味（2 つのポイント）
  • $T$ は $e_1,\ldots,e_n$ の行き先で決まっている： 2 つの線形写像 $T,T':\mathbb{K}^n\to V$ が $T(e_i)=T'(e_i)$（$1\le i\le n$）を満たせば $T=T'$。
  • $T:\mathbb{K}^n\to V$ を与えることと，$v_1,\ldots,v_n\in V$ を与えることは等価： 対応 $T\mapsto(T(e_1),\ldots,T(e_n))$ は全単射。
補題 5.1 の証明（クリックで展開）
(1) $T_{v_1,\ldots,v_n}$ が線形写像であること：
$x,y\in\mathbb{K}^n$，$a\in\mathbb{K}$ に対して $$T_{v_1,\ldots,v_n}(x+y) = \sum_i(x_i+y_i)v_i = \sum_i x_iv_i + \sum_i y_iv_i = T_{v_1,\ldots,v_n}(x) + T_{v_1,\ldots,v_n}(y)$$ $$T_{v_1,\ldots,v_n}(ax) = \sum_i(ax_i)v_i = a\sum_i x_iv_i = aT_{v_1,\ldots,v_n}(x)$$ (L1)(L2) をみたす。また $T_{v_1,\ldots,v_n}(e_i) = v_i$ は定義より明らか。

(2) $T_{T(e_1),\ldots,T(e_n)} = T$ であること：
任意の $x=(x_1,\ldots,x_n)^\top\in\mathbb{K}^n$ に対して $$T_{T(e_1),\ldots,T(e_n)}(x) = \sum_i x_iT(e_i) = T\!\left(\sum_i x_ie_i\right) = T(x)$$ （$T$ の線形性を使った）。写像として一致するので $T_{T(e_1),\ldots,T(e_n)} = T$。
$\blacksquare$
例 — 行列表示との関係

$V = \mathbb{K}^m$，$v_j = $ $A$ の第 $j$ 列（$A\in M_{m,n}(\mathbb{K})$）とすると， $$T_{v_1,\ldots,v_n}(x) = x_1v_1+\cdots+x_nv_n = Ax$$ これはちょうど行列 $A$ による線形写像 $T_A$ に一致する。

補題 5.1(2) を $V=\mathbb{K}^m$ に適用すると： $$T_{T(e_1),\ldots,T(e_n)} = T \iff \text{$T$ の行列表示} = \bigl(T(e_1)\mid\cdots\mid T(e_n)\bigr)$$ つまり線形写像の行列表示は「基本単位ベクトルの行き先を並べたもの」（系 3.4 の設定と整合）。

例 — $V$ が一般のベクトル空間の場合

$V = M_2(\mathbb{K})$（$2\times 2$ 行列の空間），$n=2$ として $$v_1 = \begin{pmatrix}1&0\\0&0\end{pmatrix}, \quad v_2 = \begin{pmatrix}0&1\\1&0\end{pmatrix}$$ とおくと，$T_{v_1,v_2}:\mathbb{K}^2\to M_2(\mathbb{K})$ は $$T_{v_1,v_2}\!\begin{pmatrix}x_1\\x_2\end{pmatrix} = x_1\begin{pmatrix}1&0\\0&0\end{pmatrix} + x_2\begin{pmatrix}0&1\\1&0\end{pmatrix} = \begin{pmatrix}x_1&x_2\\x_2&0\end{pmatrix}$$ これは $\mathbb{K}^2$ から対称行列の部分空間への線形写像で，$T(e_1)=v_1$，$T(e_2)=v_2$。

Theorem 5.2

定理 5.2 — $\operatorname{Im}T_{v_1,\ldots,v_n}$ と生成する部分空間

定理 5.2 $V$：$\mathbb{K}$-ベクトル空間とする。
  1. $v_1,\ldots,v_n\in V$ に対して $$\langle v_1,\ldots,v_n\rangle_{\mathbb{K}} = \operatorname{Im}T_{v_1,\ldots,v_n}$$
  2. $T:\mathbb{K}^n\to V$（$\mathbb{K}$-線形写像）に対して $$\operatorname{Im}(T) = \langle T(e_1),\ldots,T(e_n)\rangle_{\mathbb{K}}$$
  3. $v_1,\ldots,v_n\in V$ のとき，$T_{v_1,\ldots,v_n}:\mathbb{K}^n\to V$ が全射になるための必要十分条件は $$\langle v_1,\ldots,v_n\rangle_{\mathbb{K}} = V$$
定理 5.2 の証明（クリックで展開）
(1)：定義を展開するだけ。 $$\operatorname{Im}T_{v_1,\ldots,v_n} = \{T_{v_1,\ldots,v_n}(x)\mid x\in\mathbb{K}^n\} = \{x_1v_1+\cdots+x_nv_n \mid x_1,\ldots,x_n\in\mathbb{K}\} = \langle v_1,\ldots,v_n\rangle_{\mathbb{K}}$$ （最後の等号は定義 2.2 の span の定義そのもの）。

(2)：補題 5.1(2) より $T = T_{T(e_1),\ldots,T(e_n)}$。両辺の $\operatorname{Im}$ をとり (1) を適用すると $$\operatorname{Im}(T) = \operatorname{Im}T_{T(e_1),\ldots,T(e_n)} = \langle T(e_1),\ldots,T(e_n)\rangle_{\mathbb{K}}$$
(3)：$T_{v_1,\ldots,v_n}$ が全射 $\iff$ $\operatorname{Im}T_{v_1,\ldots,v_n} = V$（全射の定義）$\iff$ $\langle v_1,\ldots,v_n\rangle_{\mathbb{K}} = V$（(1) より）。
$\blacksquare$
読み方

(1)は「$T_{v_1,\ldots,v_n}$ の像 = $v_1,\ldots,v_n$ が張る部分空間」という，記号 $\operatorname{Im}$ と $\langle\ \rangle_\mathbb{K}$ の橋渡し。 (3)はそこから直ちに従う「全射性 = 生成すること」という言い換え。

Definition 5.3

定義 5.3 — 生成する（generate）／張る（span）

定義 5.3 $V$：$\mathbb{K}$-ベクトル空間とする。$v_1,\ldots,v_n\in V$ が $V$ を（$\mathbb{K}$上）生成する（generate）（張る，span）とは $$\langle v_1,\ldots,v_n\rangle_{\mathbb{K}} = V$$ となることをいう。このとき $v_1,\ldots,v_n$ を $V$ の生成系・生成元という。
定理5.2(3) との関係

$v_1,\ldots,v_n$ が $V$ を生成する $\iff$ $T_{v_1,\ldots,v_n}$ が全射。 「生成系を与える」ことと「$\mathbb{K}^n\to V$ の全射線形写像を与える」ことは同じ内容の言い換えになっている。

Definition 5.4

定義 5.4 — 1次独立（linearly independent）

動機

生成する（＝全射）の言い換えが手に入ったので，次は $T_{v_1,\ldots,v_n}:\mathbb{K}^n\to V$ が単射になるための必要十分条件を考えたい。

定義 5.4 $V$：$\mathbb{K}$-ベクトル空間とする。$v_1,\ldots,v_n\in V$ が（$\mathbb{K}$上）1次独立（linearly independent）であるとは，$a_1,\ldots,a_n\in\mathbb{K}$ であって $$a_1v_1+\cdots+a_nv_n = 0\in V$$ をみたすものは $a_1=\cdots=a_n=0$ に限ることをいう。
否定形（1次従属）で捉える

対偶的に言えば，$v_1,\ldots,v_n$ が1次独立でない（1次従属）とは，$a_1,\ldots,a_n$ の少なくとも1つが $0$ でないのに $a_1v_1+\cdots+a_nv_n=0$ となる組が存在すること。このとき，ある $v_i$ は残りの一次結合で書ける （$a_i\neq0$ なら $v_i = -\tfrac{1}{a_i}\sum_{j\neq i}a_jv_j$）。

期末前ばらし問題候補 その1

$V$：$\mathbb{C}$-ベクトル空間，$v_1,\ldots,v_n\in V$ であるとき，$v_1,\ldots,v_n$ が $\mathbb{C}$ 上1次独立であるとはどういうことか，定義を述べよ。

解答の型：「$a_1,\ldots,a_n\in\mathbb{C}$ であって $a_1v_1+\cdots+a_nv_n=0$ をみたすものは，$a_1=\cdots=a_n=0$ に限ること」。 定義 5.4 の $\mathbb{K}$ を $\mathbb{C}$ に置き換えるだけだが，量化子（「任意の」「存在する」「限る」）の順序を正確に書けるかが問われる。

Corollary 5.5

系 5.5 — 1次独立 ⟺ 単射

系 5.5 $V$：$\mathbb{K}$-ベクトル空間，$v_1,\ldots,v_n\in V$ とする。以下は同値：
(a) $v_1,\ldots,v_n$ は $\mathbb{K}$上1次独立 $\iff$ (b) $T_{v_1,\ldots,v_n}:\mathbb{K}^n\to V$ は単射
系 5.5 の証明（クリックで展開）
$$\operatorname{Ker}T_{v_1,\ldots,v_n} = \left\{\begin{pmatrix}a_1\\\vdots\\a_n\end{pmatrix}\in\mathbb{K}^n \;\middle|\; a_1v_1+\cdots+a_nv_n=0\right\}$$ なので，(a) はちょうど $\operatorname{Ker}T_{v_1,\ldots,v_n}=\{0\}$ を言い換えたものになっている。 定理 3.3（単射 $\iff$ $\operatorname{Ker}(T)=\{0\}$）を $T=T_{v_1,\ldots,v_n}$ に適用すれば $$\text{(a)} \iff \operatorname{Ker}T_{v_1,\ldots,v_n}=\{0\} \iff \text{(b)}$$
$\blacksquare$
Corollary 5.6

系 5.6 — $\dim\langle v_1,\ldots,v_n\rangle_{\mathbb{K}} = \operatorname{rank}(v_1\mid\cdots\mid v_n)$

系 5.6 $v_1,\ldots,v_n\in\mathbb{K}^m$ に対して $$\dim\langle v_1,\ldots,v_n\rangle_{\mathbb{K}} = \operatorname{rank}(v_1\mid\cdots\mid v_n)$$ （右辺は $v_1,\ldots,v_n$ を列に並べた $m\times n$ 行列のランク）
系 5.6 の証明（クリックで展開）
$T_{v_1,\ldots,v_n}(e_i)=v_i$（$1\le i\le n$）なので， $$T_{v_1,\ldots,v_n}:\mathbb{K}^n\longrightarrow\mathbb{K}^m$$ の行列表示はちょうど $(v_1\mid\cdots\mid v_n)$。よって定理 4.7（$\dim\operatorname{Im}(T)=\operatorname{rank}A$）と定理 5.2(1) より $$\dim\langle v_1,\ldots,v_n\rangle_{\mathbb{K}} = \dim\operatorname{Im}T_{v_1,\ldots,v_n} = \operatorname{rank}(v_1\mid\cdots\mid v_n)$$
$\blacksquare$
例

$v_1=(1,2,0)^\top$，$v_2=(2,4,0)^\top$，$v_3=(0,0,1)^\top\in\mathbb{R}^3$ とすると， $\operatorname{rank}\begin{pmatrix}1&2&0\\2&4&0\\0&0&1\end{pmatrix}=2$（$v_2=2v_1$ で冗長）なので $\dim\langle v_1,v_2,v_3\rangle_{\mathbb{R}}=2$。実際 $\langle v_1,v_2,v_3\rangle_{\mathbb{R}}=\langle v_1,v_3\rangle_{\mathbb{R}}$ で，これは $v_1,v_3$ が張る平面。

Summary

まとめ — $T:\mathbb{K}^n\to V$ に関する同値な言い換え

§5 の核心
言い換え内容
$T:\mathbb{K}^n\to V$ を与える $v_1=T(e_1),\ldots,v_n=T(e_n)\in V$ を与えることと等価（補題5.1）
$T$ の決定 $T$ は基本単位ベクトルの行き先 $(T(e_1),\ldots,T(e_n))$ で一意に決まる（補題5.1）
$V=\mathbb{K}^m$ のとき 行き先を並べた行列 $A=(v_1\mid\cdots\mid v_n)$ が $T$ の行列表示
$T_{v_1,\ldots,v_n}$ が全射 $\iff$ $v_1,\ldots,v_n$ が $V$ を生成する：$\langle v_1,\ldots,v_n\rangle_{\mathbb{K}}=V$（定理5.2(3)・定義5.3）
$T_{v_1,\ldots,v_n}$ が単射 $\iff$ $v_1,\ldots,v_n$ が $\mathbb{K}$上1次独立（系5.5）
$V=\mathbb{K}^m$ のとき次元 $\dim\langle v_1,\ldots,v_n\rangle_{\mathbb{K}}=\operatorname{rank}(v_1\mid\cdots\mid v_n)$（系5.6）

直感的な言葉： 線形写像 $T_{v_1,\ldots,v_n}:\mathbb{K}^n\to V$ の「全射性」は生成系であることと，「単射性」は1次独立であることと，それぞれぴったり対応する。 §6 ではこの両方を同時にみたす場合（＝基底）を扱う。

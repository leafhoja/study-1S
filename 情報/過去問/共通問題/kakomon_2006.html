大問 1

誤り指摘問題

問1 — 4つの文章の誤りを指摘する

問題

以下の文章にはそれぞれ誤りがある。その誤りを指摘し、誤りと判断する主な理由を簡潔に述べよ。

(a) 音楽CDはサンプリング周波数が44100Hzであり、理論上周波数が44100Hzの音まで再現できる。

(b) 音楽CDが量子化のために16ビットを用いている理由は、人間の可聴域（音を音として感じられる周波数帯域）が20Hzから20000Hz程度であるためである。

(c) インターネットでメールを出すには、送信者がメールを書くコンピュータと受信者がメールを読むコンピュータが、直接ケーブルで結ばれている必要がある。

(d) 公開鍵暗号方式でメッセージを送る際は、送信者と受信者が鍵をお互いに公開し合い、公開された鍵を用いて暗号化と復号を行う。

解答を見る

(a) 誤り：標本化定理（サンプリング定理）により、サンプリング周波数$f_s$で再現できるのはその半分の周波数、すなわち$f_s/2$まで（ナイキスト周波数）である。したがって44100Hzでサンプリングした場合、理論上再現できるのは44100/2=22050Hzまでであり、「44100Hzの音まで再現できる」というのは誤り。

(b) 誤り：量子化ビット数（16ビット）は、音の周波数帯域（可聴域）とは無関係の話である。16ビットは音の振幅（音の大きさ、強弱）を何段階で表現するか（$2^{16}=65536$段階）を決めるものであり、可聴域（20Hz〜20000Hz、これはサンプリング周波数の設定根拠になる話）とは別の概念を混同している誤りである。

(c) 誤り：インターネットのメール送受信では、送信者・受信者のコンピュータが直接ケーブルで結ばれている必要はない。ルータなどの中継機器を経由し、パケットが分割されて間接的に転送されることで、直接接続がなくても通信できる。

(d) 誤り：公開鍵暗号方式では、送信者と受信者が「お互いに」鍵を公開し合うのではない。受信者だけが鍵ペア（公開鍵・秘密鍵）を生成し公開鍵のみを公開する。送信者はその公開鍵を使って暗号化し、受信者は自分だけが持つ秘密鍵（公開されていない）で復号する。「お互いに鍵を公開し合う」「同じ公開された鍵で暗号化と復号を行う」という点が誤り。

解(a) サンプリング定理により再現できるのは44100/2=22050Hzまで　(b) 16ビットは振幅の段階数を決めるものであり可聴域とは無関係　(c) 中継機器を経由すればよく直接ケーブルで結ばれている必要はない　(d) 鍵を公開するのは受信者のみであり送信者と鍵を公開し合うわけではない
背景知識 — サンプリング・量子化・暗号方式の「よくある誤解」の共通点

この問題の(a)〜(d)はいずれも、情報の分野で頻出する誤解のパターンを扱っている。(a)と(b)はディジタル音声を特徴づける2つの独立したパラメタ、すなわち「時間軸方向の分解能（サンプリング周波数）」と「振幅方向の分解能（量子化ビット数）」を混同する誤りであり、両者はそれぞれ別々の物理的根拠（前者は可聴域の上限、後者は必要な音量の分解能）に基づいて決められている。(c)はインターネットの本質である「パケット交換によるルータ経由の間接通信」を、電話回線のような「回線交換による直接接続」と混同する誤りである。(d)は公開鍵暗号方式の非対称性（鍵ペアを持つのは受信者だけであり、公開鍵と秘密鍵は異なる役割を持つ）を、対称鍵暗号方式（送受信者が同一の鍵を共有する）の発想で捉えてしまう誤りである。いずれも「似て非なる2つの概念の役割を正確に区別できているか」を問う問題になっている。

大問 2

分割型再帰計算 f(p,q)

問2 — 配列の最大値を求める分割統治アルゴリズム

問題

要素の値が整数値で添字の値が1〜nである配列$A(=A_1\cdots A_n)$がある。分割型の計算$f$について考える。$f$は2つのパラメタ（整数値）を与えられ、1つの整数値を結果として返す。パラメタ$p,q$を与えられた時の計算結果を$f(p,q)$と表す。

与えられたパラメタをpとq (1≤p≤q≤n) とする。 if q=p then return Ap else r ← (p+q)/2 の整数部分 a ← f(p,r) b ← f(r+1,q) if a>b then return a else return b endif endif

配列の値が先頭から順に$(4,8,2,3,7)$である時（$n=5$）、$f(1,1)=4$、$f(3,3)=2$、$f(1,2)=8$、$f(2,5)=8$となる。

(a) 配列の値の並び順が上記と同じである時、$f(4,4)$、$f(3,5)$、$f(1,5)$のそれぞれの値を示せ。
(b) 一般の$n(n>0)$について、$f(1,n)$の値の意味を述べ、その理由を簡潔に説明せよ。
(c) (a)と同じ配列の値に対して$f(1,4)$を計算する場合、計算$f$は何回使われるか。回数を答えよ。
(d) $f(1,n)$を計算するために、計算$f$が使われる回数を$n$の式として求めよ。

解答を見る

配列$A=(4,8,2,3,7)$（$A_1=4,A_2=8,A_3=2,A_4=3,A_5=7$）として、既知の値$f(1,1)=4$、$f(3,3)=2$、$f(1,2)=8$、$f(2,5)=8$を手がかりに順に計算する。

(a)

$f(4,4)$：$q=p=4$なので$A_4=3$を返す。よって$f(4,4)=\mathbf{3}$。

$f(3,5)$：$p=3,q=5$、$r=(3+5)/2=4$（整数部分）。$a=f(3,4)$、$b=f(5,5)=A_5=7$を求める必要がある。 さらに$f(3,4)$：$p=3,q=4$、$r=(3+4)/2=3$（整数部分）。$a'=f(3,3)=2$（既知）、$b'=f(4,4)=3$（上で求めた）。$a'>b'$すなわち$2>3$は偽なので、elseの分岐によりbを返し$f(3,4)=\mathbf{3}$。 したがって$f(3,5)$では$a=f(3,4)=3$、$b=f(5,5)=7$となり、$a>b$すなわち$3>7$は偽なのでbを返し、$f(3,5)=\mathbf{7}$。

$f(1,5)$：$p=1,q=5$、$r=(1+5)/2=3$。$a=f(1,3)$、$b=f(4,5)$を求める必要がある。 $f(1,3)$：$p=1,q=3$、$r=(1+3)/2=2$。$a'=f(1,2)=8$（既知）、$b'=f(3,3)=2$（既知）。$a'>b'$すなわち$8>2$は真なのでaを返し、$f(1,3)=\mathbf{8}$。 $f(4,5)$：$p=4,q=5$、$r=(4+5)/2=4$（整数部分）。$a'=f(4,4)=3$（上で求めた）、$b'=f(5,5)=7$。$a'>b'$すなわち$3>7$は偽なのでbを返し、$f(4,5)=\mathbf{7}$。 したがって$f(1,5)$では$a=f(1,3)=8$、$b=f(4,5)=7$となり、$a>b$すなわち$8>7$は真なのでaを返し、$f(1,5)=\mathbf{8}$。

(b) $f(1,n)$の値は、配列$A_1,\dots,A_n$の中の最大値である。理由：このアルゴリズムは配列を再帰的に半分ずつに分割し（$f(p,r)$と$f(r+1,q)$）、それぞれの半分の中での最大値を求めた上で（$q=p$の基底ケースでは単一要素がその区間の最大値そのものである）、2つの半分の最大値同士を比較して大きい方を返す、という分割統治法（divide and conquer）になっている。これを再帰的に繰り返すことで、最終的に区間全体$[1,n]$の最大値が求まる。

(c) $f(1,4)$の呼び出し回数を、再帰呼び出しの構造をたどって数える。$f(1,4)$自身（1回）は$f(1,2)$と$f(3,4)$を呼ぶ。$f(1,2)$（1回）は$f(1,1)$と$f(2,2)$を呼ぶ（2回）。$f(3,4)$（1回）は$f(3,3)$と$f(4,4)$を呼ぶ（2回）。したがって合計は、$f(1,4)$自身1回＋$f(1,2)$1回＋$f(3,4)$1回＋$f(1,1)$1回＋$f(2,2)$1回＋$f(3,3)$1回＋$f(4,4)$1回＝7回。

(d) 一般に、$n$個の要素に対する分割統治の呼び出し回数を$T(n)$とすると、基底ケースでは$T(1)=1$（それ自身の呼び出し1回のみ）、$n>1$のときは$T(n)=1+T(\lceil n/2\rceil)+T(\lfloor n/2\rfloor)$（自分自身の呼び出し1回に加えて、左右2つの部分区間への再帰呼び出しの回数を足す）という漸化式が成り立つ。この漸化式は「区間を要素数1になるまで分割していく二分木の総ノード数」に相当する。要素数1の区間（基底ケース）が二分木の葉に対応し、その個数は$n$個である。二分木の性質として、葉の数が$n$個であれば分割を行う内部ノードの数は$n-1$個になるので、総ノード数（＝$f$が呼ばれる総回数）は葉$n$個＋内部ノード$n-1$個＝$\mathbf{2n-1}$回となる。$n=4$の場合を確認すると$2\times4-1=7$回となり、(c)の結果と一致する。

解(a) $f(4,4)=3$、$f(3,5)=7$、$f(1,5)=8$　(b) 配列$A_1,\dots,A_n$の最大値。分割統治法により部分区間ごとの最大値を求めて比較を繰り返すため。　(c) 7回　(d) $2n-1$回
背景知識 — 分割統治法による最大値探索とその計算量

この問題の$f(p,q)$は、配列を再帰的に半分ずつに分割し、それぞれの部分区間で得られた結果（ここでは最大値）を統合するという「分割統治法（divide and conquer）」の典型例である。マージソートや高速フーリエ変換（FFT）など、多くの効率的アルゴリズムがこの「問題を半分に分割し、それぞれを再帰的に解いてから結果を統合する」という考え方を基礎にしている。(d)で求めた呼び出し回数$2n-1$は$n$に比例するオーダー（$O(n)$）であり、これは配列の先頭から順に1つずつ比較していく単純な線形探索による最大値探索の比較回数$n-1$と同じオーダーである。すなわち分割統治法を使っても、最大値を求めるという問題自体の計算量のオーダーが改善されるわけではない（改善されるのはソートのように、部分問題の解を統合する際に工夫の余地がある場合である）。この点は、分割統治法が万能に計算量を削減する魔法ではなく、問題の性質によって効果が異なることを示す好例である。

大問 3

クライアント／サーバ型構成の説明

問3 — クライアントサーバ型構成とその代表例

問題

ネットワーク上で分散処理を行うシステムの典型的な形態として、クライアントサーバ型の構成がある。このクライアントサーバ型の構成について、クライアントとは何か、サーバとは何か、両者の間でどのようにやり取りがなされるか、を含め一般的に説明せよ。さらに代表的なクライアントサーバ型のシステムを2つ挙げ、それぞれクライアントとサーバの役割を説明せよ。

解答を見る

クライアントとは、サービスや処理を要求する側のプログラム・コンピュータであり、サーバとは、その要求に応じて実際の処理を行い結果を返す側のプログラム・コンピュータである。両者はネットワークを介して通信し、クライアントがサーバに対して要求（リクエスト）を送信し、サーバはその要求を受け取って必要な処理（データの検索・計算・生成等）を行った上で、結果（レスポンス）をクライアントに返送する、という非対称な役割分担によって処理が行われる。この構成により、処理能力やデータを一括してサーバ側に集約・管理でき、多数のクライアントから共有・利用できるという利点がある。

代表例1：ウェブブラウジング。クライアント＝ウェブブラウザ（URLを指定してページを要求する）、サーバ＝ウェブサーバ（要求されたHTMLページやデータを返す）。

代表例2：電子メール。クライアント＝メールソフト（メールの送信・受信を要求する）、サーバ＝メールサーバ（メールの保管・転送・配送を行う）。

解クライアント＝要求する側、サーバ＝要求に応じて処理し結果を返す側。両者はリクエスト・レスポンスの非対称なやり取りで通信する。代表例：ウェブブラウジング（ブラウザ／ウェブサーバ）、電子メール（メールソフト／メールサーバ）
背景知識 — クライアントサーバ型とP2P型の対比

クライアントサーバ型構成の対比概念として「P2P（ピアツーピア）型」がある。クライアントサーバ型では役割が「要求する側（クライアント）」と「応じる側（サーバ）」に明確に分かれ、サーバに処理・データが集約されるのに対し、P2P型では各端末（ピア）が対等な立場にあり、特定のサーバを介さずに端末同士が直接データをやり取りする。ファイル共有ソフトのWinnyはP2P型の代表例であり、この構成は後年の共通問題2012年度大問3で扱われるWinny事件（開発者の著作権法幇助容疑をめぐる裁判）とテーマ的につながっている。クライアントサーバ型は管理・制御がしやすい反面サーバに負荷や障害が集中しやすいのに対し、P2P型は特定のサーバへの依存がなく耐障害性に優れる一方、匿名性の高さから著作権侵害などの不正利用の温床になりやすいという、それぞれ異なる長所・短所を持つ構成であることも押さえておきたい。

大問 1

プログラム内蔵方式とコンピュータの構成・概念の違いの説明

問1-1 — プログラム内蔵方式とコンピュータの基本構成

問題

次の文章の空欄A〜Gに、下の語句群からあてはまる語句を選んで入れよ。

現在のコンピュータでは、プログラムを他のデータと同列に扱うことにより、物理的な機械としての内部構造を変えることなく、どのような計算でも行うことができる。このような機構をA方式といい、発表した人物の名前にちなんでB型コンピュータと呼ぶこともある。A方式のコンピュータでは、データに対して計算処理を施すC装置、データやプログラムを保持するD装置、D装置上のプログラムに従ってC装置を駆動したり、D装置へのデータの読み書きを行うE装置によって構成される。C装置とE装置を組み合わせたものをF装置といい、Gとも呼ぶ。

語句群：チューリング、フォンノイマン、制御、演算、加算、プログラム内蔵、アドレス、オペランド、パケット交換、入出力、中央処理、主記憶、CPU、CCD

解答を見る

現在のほとんどのコンピュータは、実行すべき手順（プログラム）そのものを、計算対象のデータと同じ記憶装置の中に、データと同じ形式で格納しておく、という設計になっている。これにより、機械の配線や回路（＝物理的な内部構造）を一切変更しなくても、記憶装置に置くプログラムを書き換えるだけで、まったく異なる計算を行わせることができる。この考え方を提唱したのがフォン・ノイマンであり、彼にちなんでこの構成のコンピュータは「フォンノイマン型」とも呼ばれる。

フォンノイマン型コンピュータの構成要素は、①データに演算を施す演算装置、②プログラムとデータをともに保持する主記憶装置、③主記憶上のプログラムの指示に従って演算装置を駆動し、主記憶へのデータの読み書きを制御する入出力装置、の3つに整理できる。さらに演算装置と入出力装置を合わせたものが中央処理装置、すなわちCPU（Central Processing Unit）である。

A=プログラム内蔵／B=フォンノイマン／C=演算／D=主記憶／E=入出力／F=中央処理／G=CPU

解A=プログラム内蔵、B=フォンノイマン、C=演算、D=主記憶、E=入出力、F=中央処理、G=CPU
背景知識 — CPUのうち「制御」の役割はどこにあるか

語句群には「制御」も含まれているが、この文章の空欄には使われていない（実際にCPUの内部は演算装置と制御装置の2つからなる、という説明の仕方が教科書でよく使われる）。この設問の文章をよく読むと、Eに当たる装置の説明は「$D$装置上のプログラムに従って$C$装置を駆動したり、$D$装置へのデータの読み書きを行う」という2つの役割を1つの空欄（E＝入出力）にまとめて記述している。つまりここでは、一般に別々の装置として説明されることの多い「制御装置（演算装置を駆動する役割）」の機能を、入出力装置の説明の中に含めてしまっている、という点に注意したい。語句群に「制御」「加算」「アドレス」「オペランド」「パケット交換」「CCD」の6語が残るが、これらはこの文章の空欄には対応しておらず、他の紛らわしい選択肢として置かれているだけである。

問1-2 — 概念の違いを例とともに説明する

問題

次の(1)〜(3)について、それぞれの違いを、具体的な例を示しながら2, 3行程度で説明せよ。

(1) プログラミング言語と自然言語
(2) GUIとCUI
(3) サーバとクライアント

解答を見る

(1) プログラミング言語と自然言語：プログラミング言語は文法と意味があらかじめ形式的に厳密に定義されており、曖昧さを含まず機械的に一意に解釈できる（例：if文の条件式は必ず真か偽のどちらか一方に決まる）。これに対して自然言語は、文脈への依存性や表現の曖昧さを含み、同じ表現が複数の意味に解釈されうる（例：「彼は猫が好きな女性を愛している」という文は、「猫が好きな」のが「彼」なのか「女性」なのか一意に決まらない、係り受けの曖昧さを持つ）。

(2) GUIとCUI：GUI（Graphical User Interface）は、ウィンドウやアイコンなどの視覚的なオブジェクトを、マウスなどのポインティングデバイスで直接操作するインタフェースである（例：ファイルのアイコンをマウスでドラッグしてフォルダの上に移動させ、コピーや移動を行う）。これに対してCUI（Character User Interface）は、キーボードから文字によるコマンドを入力して操作するインタフェースである（例：mvコマンドに移動元・移動先のパスを文字列として入力し、ファイルを移動する）。

(3) サーバとクライアント：サーバは、他からの要求（リクエスト）を受け取り、それに応じた処理を行って結果を返す、サービスを提供する側のコンピュータ（プログラム）である（例：ウェブページのデータを保管し、要求に応じて送信するウェブサーバ）。クライアントは、サーバに対してサービスの提供を要求する側の、利用者が直接操作するコンピュータ（プログラム）である（例：URLを指定してウェブサーバにページのデータを要求し、受け取った内容を表示するウェブブラウザ）。

解(1) プログラミング言語＝形式的で曖昧さがなく機械的に解釈できる／自然言語＝文脈依存・曖昧さを含む　(2) GUI＝視覚的オブジェクトを直接操作／CUI＝文字コマンドを入力して操作　(3) サーバ＝要求に応じてサービスを提供する側／クライアント＝サービスを要求する利用者側
背景知識 — 「厳密に定義された言語」と「曖昧さを許す言語」

問1-2(1)で扱われている「プログラミング言語の厳密さ」と「自然言語の曖昧さ」という対比は、問1-1で見た「プログラム内蔵方式」とも密接に関係している。プログラム内蔵方式のコンピュータは、記憶装置に置かれた記号の並び（プログラム）を、一切の解釈のブレなく機械的に実行できることが前提になっている。もしプログラミング言語が自然言語のように文脈依存の曖昧さを許してしまうと、同じプログラムが実行のたびに異なる動作をしてしまい、決定的な計算を行うことができなくなってしまう。この意味で、プログラミング言語の厳密な文法・意味の定義は、フォンノイマン型コンピュータが「同じ入力に対して常に同じ結果を返す」という信頼性を実現するための、必要不可欠な土台になっていると言える。

大問 2

ファイル配置と情報量・フォルダ階層構造の走査

設定

重要なデータがファイルA〜Gに記録されており、フォルダL, M, N, P, Q, Rの下に、図1のような構成で置かれている。図中で、あるフォルダから別のフォルダ・ファイルへの矢印は、矢印の先が矢印の元の「直下」（1段下）にあることを表す。以下では「直下」は1段下だけを指し、単に「下」といった場合は複数段下にある場合も含むものとする。

図1 — 現在のファイル配置

図1の構成
  • L
    • M
      • P → A, B
      • Q → C, D
    • N
      • R → E, F
      • G（Nの直下にある、ファイル）

すなわち、Lの直下にはM, Nの2つのフォルダがあり、Mの直下にはP, Qの2つのフォルダ、Nの直下にはR（フォルダ）とG（ファイル）がある。Pの直下にはファイルA, B、Qの直下にはファイルC, D、Rの直下にはファイルE, Fがある。

問2-1(1) — ファイルの存在確率と情報量

問題

ファイルA〜Gが、それぞれ次の確率で存在するとする。

P(A)=1/4, P(B)=1/4, P(C)=1/8, P(D)=1/8, P(E)=1/8, P(F)=1/16, P(G)=1/16

(a) ファイルAにあると知ることの情報量を求めよ。
(b) どのファイルにあるかを知ることの平均情報量を求めよ。
(c) (a)で求めた情報量が、「MとNのなかでMの下にあることを知る情報量」＋「PとQのなかでPの下にあることを知る情報量」＋「AとBのなかでAにあることを知る情報量」の和になっていることを、それぞれの情報量の値を示して説明せよ。

解答を見る

ある事象が確率$p$で起こるとき、その事象が実際に起こったと知ることの情報量は$-\log_2 p$で定義される。

(a) $P(A)=1/4$なので、情報量は $$-\log_2\frac14=\mathbf{2}\ \text{ビット}$$

(b) 平均情報量（エントロピー）は、各ファイルの情報量をその確率で重みづけて合計すればよい。確率が等しいファイルをまとめると、確率$1/4$のもの（A, B）が2個、確率$1/8$のもの（C, D, E）が3個、確率$1/16$のもの（F, G）が2個ある。 $$H=2\times\left(\frac14\times2\right)+3\times\left(\frac18\times3\right)+2\times\left(\frac1{16}\times4\right)=2\times0.5+3\times0.375+2\times0.25=1+1.125+0.5=\mathbf{2.625}\ \text{ビット}$$

(c) 図1の木構造において、フォルダ配下にあるファイルの確率の合計を考える。Mの配下にはA, B, C, Dがあるので $$P(M)=P(A)+P(B)+P(C)+P(D)=\frac14+\frac14+\frac18+\frac18=\frac34,\qquad P(N)=1-P(M)=\frac14$$ Mの中でさらにPの配下（A, B）に絞られる条件付き確率は $$P(P\mid M)=\frac{P(A)+P(B)}{P(M)}=\frac{1/2}{3/4}=\frac23$$ Pの中でさらにAに絞られる条件付き確率は $$P(A\mid P)=\frac{P(A)}{P(A)+P(B)}=\frac{1/4}{1/2}=\frac12$$ これら3段階の「絞り込み」それぞれの情報量は $$-\log_2 P(M)=-\log_2\frac34=\log_2\frac43\approx0.415\ \text{ビット}\quad(\text{Mの下にあることを知る情報量})$$ $$-\log_2 P(P\mid M)=-\log_2\frac23=\log_2\frac32\approx0.585\ \text{ビット}\quad(\text{Pの下にあることを知る情報量})$$ $$-\log_2 P(A\mid P)=-\log_2\frac12=1\ \text{ビット}\quad(\text{Aにあることを知る情報量})$$ これらを足し合わせると $$0.415+0.585+1=2.0\ \text{ビット}$$ となり、(a)で求めた2ビットにちょうど一致する。これは偶然ではなく、$P(A)=P(M)\times P(P\mid M)\times P(A\mid P)$という確率の連鎖律（条件付き確率を段階的に掛け合わせると全体の確率になるという関係）の両辺で$-\log_2$をとれば、右辺の積が対数によって和に変換されるためである。すなわち「Aにあることを知る」という1つの大きな情報は、「まずMの下だと分かる」「次にその中でPの下だと分かる」「最後にその中でAだと分かる」という3段階の情報に、対数の性質によって必ずきれいに分解できる。この分解の仕方は木構造上のどの経路をたどっても成り立つ一般的な性質である。

解(a) 2ビット　(b) 2.625ビット　(c) 「Mの下」$\approx0.415$ビット＋「Pの下」$\approx0.585$ビット＋「Aにある」$1$ビット＝$2.0$ビットで(a)に一致（確率の連鎖律と対数の性質による）

問2-1(d) — 図2への最適配置

問題

ファイルを開くには、フォルダLからそのファイルまでの矢印の本数だけ秒数がかかるとする（たとえば図1の配置でファイルAを開くには、L→M→P→Aの3本の矢印をたどるので3秒かかる）。

図1の配置のとき、ファイルを開く時間の平均（すなわち平均時間 $=\sum_{X}P(X)\times(\text{Xを開くのにかかる秒数})$）を求めよ。さらに、図2のように配置を変更した場合を考え、この平均時間が最も短くなるように、空欄ア〜キにファイルA〜Gを配置せよ。またそのときの平均時間を求めよ。

図2の構成

  • L
    • M → ア, イ（Mの直下に直接ある、ファイル2つ）
    • N
      • P → ウ, エ
      • Q → オ（Qの直下に直接あるファイル）
        • R → カ, キ

すなわち図2では、Lの直下にM, Nがあり、Mの直下には直接2つのファイル（ア, イ）が置かれている。Nの直下にはP, Qがあり、Pの直下には直接2つのファイル（ウ, エ）、Qの直下には直接1つのファイル（オ）と、フォルダRがある。Rの直下には2つのファイル（カ, キ）がある。

解答を見る

図1の配置での平均時間：図1では、A, B, C, D, E, Fの6つのファイルはいずれも矢印3本先（L→○→○→ファイル）にあり、Gだけは矢印2本先（L→N→G）にある。よって平均時間は $$\frac14\times3+\frac14\times3+\frac18\times3+\frac18\times3+\frac18\times3+\frac1{16}\times3+\frac1{16}\times2=\left(\frac14+\frac14+\frac18+\frac18+\frac18+\frac1{16}\right)\times3+\frac1{16}\times2$$ $$=\frac{15}{16}\times3+\frac{1}{16}\times2=\frac{45}{16}+\frac{2}{16}=\frac{47}{16}\ \text{秒}$$ （Gだけが他より1秒短い2秒で開けることに注意。）

図2での最適配置：図2の各空欄の「深さ」（Lからの矢印の本数）を確認すると、ア, イはMの直下にある＝深さ2、ウ, エ, オはP, Qの直下にある＝深さ3、カ, キはRの直下にある＝深さ4、と3段階に分かれている。平均時間を最小にするには、確率の大きいファイルほど深さの浅い（矢印の少ない）場所に置くのが最適である――これはハフマン符号を構成するときの発想と同じで、「頻繁に使うものほど短い経路に置く」という考え方である。

確率を大きい順に並べると、A, B（各$1/4$）＞C, D, E（各$1/8$）＞F, G（各$1/16$）となっている。これを深さの浅い順に、上位2個・中位3個・下位2個として当てはめると、

ア＝A, イ＝B（深さ2、確率$1/4$の2つ）／ウ＝C, エ＝D, オ＝E（深さ3、確率$1/8$の3つ。ウ・エ・オの間の順序はどれも確率が等しいので任意）／カ＝F, キ＝G（深さ4、確率$1/16$の2つ。カ・キの順序も任意）

このときの平均時間は $$\left(\frac14+\frac14\right)\times2+\left(\frac18+\frac18+\frac18\right)\times3+\left(\frac1{16}+\frac1{16}\right)\times4=\frac12\times2+\frac38\times3+\frac18\times4=1+\frac98+\frac12$$ $$=\frac{8}{8}+\frac98+\frac48=\frac{21}{8}=\mathbf{2.625}\ \text{秒}$$

この$2.625$という値は、問2-1(b)で求めた平均情報量（エントロピー）$2.625$ビットと完全に一致している。これは偶然ではなく、A〜Gの確率がすべて$2$のべき乗の逆数（$1/4, 1/8, 1/16$のようなダイアディックな確率）になっているために、木の深さをそのまま「その事象を特定するのに必要なビット数」として使うハフマン符号的な配置が、理論的な下限であるエントロピーをちょうど達成できているためである。

解図1の平均時間：$\dfrac{47}{16}$秒　最適配置：ア=A, イ=B, ウ=C, エ=D, オ=E, カ=F, キ=G（ウエオ・カキの順は任意）　最適平均時間：$\dfrac{21}{8}=2.625$秒
背景知識 — 情報量の分解とハフマン符号は同じ木構造の2つの見方

問2-1(c)で見た「情報量の加法性」と、問2-1(d)で見た「深さの浅い場所に確率の高いファイルを置く最適配置」は、実はまったく同じ木構造・同じ確率分布から生まれる2つの異なる見方である。(c)では、木構造をたどって1つのファイルを特定するまでの各段階の「絞り込み」の情報量を足し合わせると、全体の情報量にちょうど一致することを見た。(d)では、その同じ木構造の「深さ」を符号の長さ（ここでは秒数）とみなし、確率の高いものを浅く・低いものを深く配置することで、平均の符号長（秒数）を最小化した。両者を結びつけているのは、確率がすべて$2$のべき乗の逆数になっているという特別な条件で、この条件のもとでは「最適な木の深さ」と「情報量（$-\log_2 p$）」が完全に一致する。この事実は、ハフマン符号がエントロピーという理論的下限をちょうど達成する特別な場合として理解することができる。

問2-2 — 「↓／↑」の2操作によるフォルダの巡回

問題

「↓X」（現在のフォルダの直下にあるフォルダXに入る、またはファイルXを見る）と「↑」（1つ上のフォルダに戻る）という2種類の操作だけを使って、図1に示したすべてのフォルダとファイルを、フォルダLから始めてたどっていく。次の操作の並びの空欄ク・ケ・コを埋めよ。

↓M, ↓P, ↓A, ↑, ↓B, ↑, ↑, ↓Q, ↓C, ↑, ↓D, ↑, ↑, ↑, ↓N, ク, ↓E, ↑, ケ, ↑, ↑, コ, ↑, ↑

(a) ク、ケ、コをそれぞれ埋めよ。
(b) この「↓X」「↑」という2種類の操作だけで、図1のすべてのフォルダ・ファイルを重複なくたどることができたのは、図1のようなフォルダ・ファイルの構成が、どのような性質を持っているからか述べよ。

解答を見る

(a) 操作の並びを順にたどって現在位置を確認していく。↓M, ↓P, ↓A, ↑, ↓B, ↑, ↑で「L→M→P→A→P→B→P→M」と動き、Pの中のA, Bを両方見終えてMに戻る。続く↓Q, ↓C, ↑, ↓D, ↑, ↑で「M→Q→C→Q→D→Q→M」と動き、Qの中のC, Dも両方見終えてMに戻る。さらに↑でMからLに戻り、↓NでLからNに入る。ここまででMの下のP, Q（およびその中のA, B, C, D）はすべて訪問済みであり、残っているのはNの下のR（およびE, F）とGである。

Nに入った直後なので、まずNの直下のフォルダRに入る必要がある：ク＝↓R。Rに入ったら、続く↓E, ↑でRの中のEを見てRに戻る。次にRの中のもう一方のファイルFを見る必要があるので：ケ＝↓F。Fを見た後、続く↑, ↑でR→Nと2段上に戻る。この時点でRの下のE, Fは両方訪問済みであり、残っているのはNの直下にある最後のファイルGだけなので：コ＝↓G。その後の↑, ↑でN→Lと戻り、すべてのフォルダ・ファイルの訪問を終える。

操作の並び全体を通しで確認すると：↓M, ↓P, ↓A, ↑, ↓B, ↑, ↑, ↓Q, ↓C, ↑, ↓D, ↑, ↑, ↑, ↓N, ↓R, ↓E, ↑, ↓F, ↑, ↑, ↓G, ↑, ↑となり、L, M, N, P, Q, Rの全フォルダとA〜Gの全ファイルが、それぞれちょうど1回ずつ訪問されて、最後にLに戻ってきていることが確認できる。

(b) このように「↓X（子に降りる）」と「↑（親に戻る）」の2操作だけで、すべての項目を重複なく体系的にたどることができたのは、図1のフォルダ・ファイルの構成が木構造（どの項目も親がただ1つに定まり、複数の経路で同じ場所に到達するような閉路（サイクル）を持たない構造）になっているからである。木構造では、ある場所から子の1つに降りて、そこから先をすべて調べ尽くしたら親に戻ってくる、という手順（深さ優先探索）を再帰的に繰り返すだけで、迷うことなく全体を一度ずつ訪問できる。もしフォルダの構成に閉路があったり、1つのファイルが複数のフォルダから共有されていたりすると、この単純な2操作だけでは「どこをすでに訪問したか」を管理できず、同じ場所を無限に回り続けたり、一部を訪問し忘れたりする可能性がある。

解(a) ク＝↓R、ケ＝↓F、コ＝↓G　(b) 図1の構成が木構造（親が一意で閉路を持たない構造）になっているため、「子に降りる」「親に戻る」の繰り返し（深さ優先探索）だけで全体を重複なくたどれる
背景知識 — 木構造の深さ優先探索という一般的な考え方

問2-2(b)で述べた「木構造だからこそ2操作だけの巡回で全体を尽くせる」という性質は、コンピュータのファイルシステムを扱うプログラム（たとえば「フォルダの中身をすべて一覧表示する」処理）や、ウェブページのDOM構造（HTMLの入れ子になったタグの構造）をプログラムで走査する処理など、木構造のデータを扱う場面で広く使われる、深さ優先探索（Depth-First Search, DFS）という基本的なアルゴリズムの考え方そのものである。「今いる場所の子を1つ選んで降りる」「その子の下をすべて調べ終えたら元の場所に戻る」という規則をどの階層でも同じように適用できる（再帰的に適用できる）のは、木構造に「親がただ1つ」という性質があるからこそであり、この性質が崩れる（閉路を持つ、共有ノードを持つなど）と、訪問済みかどうかを別途記録する仕組みが追加で必要になる。

問題A — 著作権・電子書籍・ICTと社会

問題

ある大学の情報の講義で、次のような（誤りを含む）レポートが提出された。

コンピュータやインターネットなど情報技術の発達に伴い、文書は紙の本という形を失い、容易に複製可能となった。複製の容易さは複製の際に本来感じるはずの罪の意識を感じさせず、大量の複製物が乱造されることになった。そこで文書作成者の利益を保護するために著作権法が作られた。

これについて、以下の点を議論せよ。

  1. 情報技術の発達以前から、著作権またはそれに類する権利として法的に保護されてきたものの例を、物としての形を持つものと持たないものから一つずつ挙げよ。
  2. コンピュータやインターネットの発達に伴って行われた、著作権に関する調整を一つ挙げ、簡潔に説明せよ。
  3. 電子書籍販売事業について考える。購入者のみが書籍を読むことができるようにしたい。個人認証技術、公開鍵暗号方式とPKI、電子署名の3つの技術がその目的にどのように役立ちうるか、各技術の内容を説明したうえで議論せよ。
  4. 情報の複製の容易さが著作権以外に及ぼした影響について、世に広く利益をもたらした具体例と、反対にリスクやコストをもたらした具体例を一つずつ挙げよ。リスクやコストについては、どのような対策がとられているかも説明せよ。
  5. 近年のICTを含む情報技術の発展が社会構造に与えた影響を、過去の技術発展が社会に与えた影響と対比しつつ説明せよ。
解答例を見る

(1) 形を持つ例として書籍・絵画・楽譜、形を持たない例として音楽の演奏・講演・舞踊などが挙げられる。著作権法は情報技術以前から存在しており、レポートの因果関係は誤りである。

(2) 例として、プログラムやデータベースを著作物として明確に保護する規定、インターネット送信に対応する公衆送信権・送信可能化権、技術的保護手段の回避に関する規定などがある。

(3) 個人認証で購入者本人を確認し、購入者の公開鍵でコンテンツ鍵を暗号化すれば対応する秘密鍵を持つ者だけが復号できる。PKIは公開鍵と本人との対応を電子証明書で保証し、電子署名は配信物の作成者と改ざんの有無を検証する。

(4) 利益の例は、研究成果・災害情報・オープンソースソフトウェアの迅速な共有。リスクの例は個人情報や偽情報の大量拡散であり、アクセス制御、暗号化、署名、削除要請、法制度などで対処する。

(5) 印刷・鉄道・電話などが情報や人の流通範囲を拡大したのと同様、ICTは通信費と複製費を急減させた。さらに、個人が世界規模で発信者になれる多対多通信や、プラットフォームへの権力集中という新しい社会構造も生んだ。

問題B — 正の実数 \(x\) の平方根を求めるアルゴリズム

問題

正の実数 \(x\) の平方根を計算する方法を次に示す。アルゴリズム1は高水準言語による記述、プログラム1はそれを機械語レベルで記述したものである。以下の設問 (1)〜(5) に答えよ。ただし \(\sqrt3=1.73205\ldots\) を利用してよい。レジスタと各メモリアドレスは実数値を保持でき、演算命令も実数を処理できるものとする。

アルゴリズム1

\(y\leftarrow0\)
while \((y+\delta)^2\le x\) do
  \(y\leftarrow y+\delta\)
done
return \(y\)

命令の意味

命令意味
load AアドレスAのデータを演算レジスタに読む。
store A演算レジスタのデータをアドレスAへ書く。
add AアドレスAの値を演算レジスタへ加える。
multiply AアドレスAの値を演算レジスタへ掛ける。
less eq A演算レジスタの値がアドレスAの値以下なら1、そうでなければ0にする。
jump AアドレスAへ実行を移す。
jumpzero A演算レジスタが0ならアドレスAへ実行を移す。
write演算レジスタのデータを出力する。
halt実行を停止する。

プログラム1

1001 load 2003 1002 add 2002 1003 store 2004 1004 multiply 2004 1005 less eq 2001 1006 jumpzero 1011 1007 load 2003 1008 add A 1009 store 2003 1010 jump 1001 1011 load B 1012 write 1013 halt 2001 \(x\) 2002 \(\delta\) 2003 0 2004 0
  1. アルゴリズム1を \(x=3.0,\delta=0.03\) として実行した結果を答えよ。
  2. 結果が得られるまでに実行される繰返しの回数を \(x,\delta\) を用いて表せ。
  3. プログラム1を同じ入力で実行し、アドレス1005の命令を初めて実行する直前の演算レジスタのデータを答えよ。
  4. プログラム1がアルゴリズム1と対応するよう、空欄A、Bを埋めよ。
  5. 1命令に0.001秒かかるとき、停止までの時間を導出過程とともに答えよ。
解答を見る

(1) \(0.03\times57=1.71\) では \((1.74)^2>3\) となるため、結果は \(1.71\)。

(2) 反復回数は \(\left\lfloor\sqrt{x}/\delta\right\rfloor\)。ただし \(\sqrt{x}/\delta\) が整数のときもその整数回となる。

(3) 最初は \(y=0\) なので、1001〜1004により \((0+\delta)^2=0.0009\)。

(4) 1008では \(y\) に \(\delta\) を加えるため A=2002。1011では現在の \(y\) を読むため B=2003。

(5) 反復を \(n=57\) 回行う。条件成功時は1001〜1010の10命令、最後の条件失敗時は1001〜1006と1011〜1013の9命令なので、合計 \(10n+9=579\) 命令、\(0.579\) 秒。

解(1) \(1.71\)　(2) \(\lfloor\sqrt{x}/\delta\rfloor\) 回　(3) \(0.0009\)　(4) A=2002, B=2003　(5) \(0.579\) 秒

1 $f(x)=x^2$ の一様連続性

問題文

一変数関数 $f(x) = x^2$ を考える。定義域 $D$ が以下の場合に，$f$ が $D$ 上一様連続かどうかを（証明を付けて）答えよ。

  1. $D = \mathbb{R}$
  2. $D = \{x \in \mathbb{R} \mid x > 0\}$
  3. $D = (0,1)$
一様連続性の定義

$f$ が $D$ 上一様連続とは：任意の $\varepsilon>0$ に対しある $\delta>0$ が存在して，$x,y\in D$，$|x-y|<\delta$ を満たすすべての $x,y$ に対し $|f(x)-f(y)|<\varepsilon$ となること。$\delta$ が点の位置によらず一様に取れる点が，各点での連続性との違い。

🧠 方針を立てる前に
🔄 非一様連続性の見抜き方

$f(x)-f(y) = (x-y)(x+y)$ なので，$x-y$ が小さくても $x+y$ がいくらでも大きくなれる定義域では，$|f(x)-f(y)|$ を大きくできてしまう。$D$ が非有界（$\mathbb{R}$ や $(0,\infty)$）なら，$x,y$ を無限遠に飛ばしつつ差 $x-y$ を固定的に小さく保てば反例が作れる。逆に $D$ が有界なら $x+y$ 自体が押さえられるので，一様連続性が期待できる。

📝 解答 (1) — $D=\mathbb{R}$：一様連続でない

背理法で示す。$f$ が $\mathbb{R}$ 上一様連続と仮定する。$\varepsilon = 1$ に対し，ある $\delta>0$ が存在して

$$|x-y|<\delta \implies |f(x)-f(y)|<1.$$

$n > 1/\delta$ を満たす自然数 $n$ をとり，$x_n = n,\ y_n = n+\dfrac{1}{n}$ とおく。このとき

$$|x_n-y_n| = \frac{1}{n} < \delta$$

であるにもかかわらず，

$$|f(x_n)-f(y_n)| = |x_n-y_n|\,|x_n+y_n| = \frac{1}{n}\left(2n+\frac{1}{n}\right) = 2+\frac{1}{n^2} > 2 > 1.$$

これは仮定に矛盾する。よって $f$ は $\mathbb{R}$ 上一様連続でない。$\blacksquare$

📝 解答 (2) — $D=\{x>0\}$：一様連続でない

(1) と全く同じ $x_n=n,\ y_n=n+\dfrac{1}{n}$ はいずれも $D$ に属するので，同じ議論がそのまま使える。よって $f$ は $D$ 上一様連続でない。$\blacksquare$

📝 解答 (3) — $D=(0,1)$：一様連続である

$\varepsilon>0$ を任意に与える。$\delta := \dfrac{\varepsilon}{2}$ とおく。$x,y\in(0,1)$ が $|x-y|<\delta$ を満たすとする。$0<x,y<1$ より $x+y<2$ なので，

$$|f(x)-f(y)| = |x-y|\,|x+y| < \delta \cdot 2 = \varepsilon.$$

$\delta$ は $\varepsilon$ のみから決まり，$x,y$ の位置に依存しないので，$f$ は $(0,1)$ 上一様連続である。$\blacksquare$

🔑 ポイントまとめ
  • 因数分解 $x^2-y^2=(x-y)(x+y)$ が全ての鍵。非有界な定義域では $x+y$ を大きくして差を稼ぐ反例が作れ，有界な定義域では $x+y$ 自体に一様な上限があるので直接評価できる。
  • 反例の作り方：「差が一定に小さいまま，和がいくらでも大きくなる」ような2点列 $x_n,y_n$ を探す。$x_n=n,\,y_n=n+1/n$ は差 $1/n\to0$ でありながら積 $|x_n-y_n||x_n+y_n|\to 2$ に収束する典型例。
  • 有界区間では「一様連続性の $\delta$ が $\varepsilon$ だけで決まる」ことを直接示すのが最短。Heine–Cantor の定理（$[0,1]$ でのコンパクト性）を援用してもよいが，この問題では直接評価の方が速い。
2 $\displaystyle\int_0^1 x\,dx$ をリーマン積分の定義から計算

問題文

定積分 $\displaystyle\int_0^1 x\,dx$ をリーマン積分の定義に従って計算せよ。

🧠 方針
🔄 上下和で挟み撃ちにする

「定義に従って」とあるので，区分求積の上和・下和を計算し，両者が同じ極限値に収束することを示す必要がある。$f(x)=x$ は単調増加だから，各小区間での下限・上限はそれぞれ左端・右端の値になる——これが計算を単純にする。

📝 解答

区間 $[0,1]$ を $n$ 等分する分割 $\Delta_n : 0=x_0<x_1<\cdots<x_n=1$，$x_k = \dfrac{k}{n}$ を考える。$f(x)=x$ は単調増加なので，各小区間 $[x_{k-1},x_k]$ での下限・上限は

$$\inf_{[x_{k-1},x_k]} f = x_{k-1} = \frac{k-1}{n}, \qquad \sup_{[x_{k-1},x_k]} f = x_k = \frac{k}{n}.$$

下和：

$$L(\Delta_n) = \sum_{k=1}^n \frac{k-1}{n}\cdot\frac{1}{n} = \frac{1}{n^2}\sum_{k=0}^{n-1}k = \frac{1}{n^2}\cdot\frac{(n-1)n}{2} = \frac{n-1}{2n}.$$

上和：

$$U(\Delta_n) = \sum_{k=1}^n \frac{k}{n}\cdot\frac{1}{n} = \frac{1}{n^2}\sum_{k=1}^{n}k = \frac{1}{n^2}\cdot\frac{n(n+1)}{2} = \frac{n+1}{2n}.$$

$n\to\infty$ のとき

$$L(\Delta_n) = \frac{1}{2}-\frac{1}{2n} \to \frac{1}{2}, \qquad U(\Delta_n) = \frac{1}{2}+\frac{1}{2n} \to \frac{1}{2}.$$

下積分 $\underline{\int_0^1} f \geq L(\Delta_n)$，上積分 $\overline{\int_0^1} f \leq U(\Delta_n)$ が任意の $n$ で成り立ち，両辺とも $\dfrac12$ に収束するので，はさみうちより

$$\underline{\int_0^1} f = \overline{\int_0^1} f = \frac{1}{2}.$$

下積分と上積分が一致するので $f$ はリーマン積分可能であり，

$$\int_0^1 x\,dx = \boxed{\frac{1}{2}}.$$
🔑 ポイントまとめ
  • 単調関数では上下和の計算が簡単：各小区間の inf/sup がそれぞれ左端・右端の値そのものになるので，$\varepsilon$-論法を経由せず直接和の公式 $\sum k$ に帰着できる。
  • 「定義に従って」の意味：単に $\dfrac{x^2}{2}$ を代入するのではなく，上和と下和がともに同じ極限に収束することを示して初めてリーマン可積分性と積分値が確定する，という論理の骨格を書く。
3 積分方程式 $f(x) = e^x + \displaystyle\int_1^2 x f(x)\,dx$

問題文

$f(x) = e^x + \displaystyle\int_1^2 x f(x)\,dx$ を満たす一変数関数 $f(x)$ を求めよ。

🧠 方針を立てる前に
🔄 積分項は実は「ただの定数」

右辺の $\displaystyle\int_1^2 x f(x)\,dx$ は積分区間が $1$ から $2$ までの定積分なので，積分してしまえば $x$ に依存しない数になる（積分変数の $x$ と外側の $f(x)$ の $x$ が同じ文字を使っているが，紛らわしいだけで別物——積分変数は $t$ に置き換えて考えるとよい）。この定数を $C$ とおけば $f(x)=e^x+C$ という形が先に決まり，あとは $C$ の自己無撞着な方程式を解けばよい。

📝 解答

積分変数を $t$ に取り替えて $\displaystyle C := \int_1^2 t f(t)\,dt$（$x$ に依らない定数）とおく。このとき与式は

$$f(x) = e^x + C \qquad \text{（$C$ は未知定数）}$$

の形をしている。この $f$ を $C$ の定義式に代入すると，$C$ 自身が満たすべき方程式が得られる：

$$C = \int_1^2 t\bigl(e^t+C\bigr)\,dt = \int_1^2 t e^t\,dt + C\int_1^2 t\,dt.$$

各項を計算する。部分積分（または $\frac{d}{dt}[(t-1)e^t] = e^t+(t-1)e^t = te^t$ に注意）より

$$\int_1^2 t e^t\,dt = \Bigl[(t-1)e^t\Bigr]_1^2 = 1\cdot e^2 - 0\cdot e^1 = e^2.$$ $$\int_1^2 t\,dt = \left[\frac{t^2}{2}\right]_1^2 = 2-\frac12 = \frac32.$$

よって

$$C = e^2 + \frac{3}{2}C \iff -\frac{1}{2}C = e^2 \iff C = -2e^2.$$

ゆえに

$$f(x) = \boxed{e^x - 2e^2}.$$

検算：$\displaystyle\int_1^2 t f(t)\,dt = \int_1^2 te^t\,dt - 2e^2\int_1^2 t\,dt = e^2 - 2e^2\cdot\frac32 = e^2-3e^2=-2e^2=C$ ✓

🔑 ポイントまとめ
  • 積分方程式の定石：定積分（区間が定数）が式の中に現れたら，それは未知の定数として名前を付けてしまう（$C:=\int_1^2 tf(t)\,dt$）。これにより $f$ の形が先に決まり，あとは $C$ についての通常の方程式に帰着する。
  • 変数の衝突に注意：問題文では積分変数も外側の変数も同じ $x$ で書かれているが，これは実質的に束縛変数（ダミー変数）なので $t$ などに置き換えて考えると混乱しない。
  • 検算の習慣：求めた $f$ を $C$ の定義式に戻して同じ値が出るか確認するのが，このタイプの問題での必須チェック。
4 重積分の計算（$a$ は正の定数）

問題文

次の重積分を計算せよ。ただし $a$ は正の定数とする。

  1. $\displaystyle\iint_D (x+y)^a\,dxdy,\quad D=\{(x,y)\mid 0\le x\le 1,\ 0\le y\le 1\}$
  2. $\displaystyle\iint_D x^2y^2\,dxdy,\quad D=\{(x,y)\mid |x|+|y|\le a\}$
  3. $\displaystyle\iint_D e^{y/x}\,dxdy,\quad D=\{(x,y)\mid 0<x\le a,\ 0\le y\le x\}$
📝 解答 (1)

$D$ は長方形領域なので累次積分に直せる。$x$ について先に積分する：

$$\int_0^1 (x+y)^a\,dx = \left[\frac{(x+y)^{a+1}}{a+1}\right]_{x=0}^{1} = \frac{(1+y)^{a+1}-y^{a+1}}{a+1}.$$

これを $y$ について $0$ から $1$ まで積分する：

$$\iint_D (x+y)^a\,dxdy = \frac{1}{a+1}\int_0^1\Bigl[(1+y)^{a+1}-y^{a+1}\Bigr]dy.$$ $$\int_0^1(1+y)^{a+1}dy = \left[\frac{(1+y)^{a+2}}{a+2}\right]_0^1 = \frac{2^{a+2}-1}{a+2}, \qquad \int_0^1 y^{a+1}dy = \frac{1}{a+2}.$$

したがって

$$\iint_D (x+y)^a\,dxdy = \frac{1}{a+1}\cdot\frac{2^{a+2}-2}{a+2} = \boxed{\frac{2\bigl(2^{a+1}-1\bigr)}{(a+1)(a+2)}}.$$

検算（$a=1$）：公式値 $\dfrac{2(4-1)}{2\cdot3}=1$。一方 $\iint_D(x+y)\,dxdy = \int_0^1\left(x+\frac12\right)dx = \frac12+\frac12=1$ ✓

📝 解答 (2)

$D=\{|x|+|y|\le a\}$ は原点対称な菱形で，被積分関数 $x^2y^2$ は $x,y$ それぞれについて偶関数だから，第1象限部分の4倍として計算できる：

$$\iint_D x^2y^2\,dxdy = 4\iint_{\substack{x,y\ge 0\\ x+y\le a}} x^2y^2\,dxdy.$$

第1象限部分では $0\le x\le a$，$0\le y\le a-x$ なので，$y$ について先に積分する：

$$\int_0^{a-x} y^2\,dy = \frac{(a-x)^3}{3}.$$

続いて $x$ について積分する。$(a-x)^3 = a^3-3a^2x+3ax^2-x^3$ に注意して展開すると

$$\int_0^a x^2(a-x)^3\,dx = \int_0^a\left(a^3x^2-3a^2x^3+3ax^4-x^5\right)dx = \frac{a^6}{3}-\frac{3a^6}{4}+\frac{3a^6}{5}-\frac{a^6}{6}.$$

通分（分母60）すると $\dfrac{20-45+36-10}{60}a^6 = \dfrac{1}{60}a^6$。よって

$$\iint_{\substack{x,y\ge0\\x+y\le a}} x^2y^2\,dxdy = \frac13\cdot\frac{a^6}{60}=\frac{a^6}{180}, \qquad \iint_D x^2y^2\,dxdy = 4\cdot\frac{a^6}{180} = \boxed{\frac{a^6}{45}}.$$
📝 解答 (3)

$x$ を固定して $y$ について先に積分する。$u=y/x$（$x$ は定数なので $dy=x\,du$）と置換すると，$y:0\to x$ に対し $u:0\to1$：

$$\int_0^x e^{y/x}\,dy = \int_0^1 e^{u}\,x\,du = x\bigl[e^u\bigr]_0^1 = x(e-1).$$

続いて $x$ について $0$ から $a$ まで積分する：

$$\iint_D e^{y/x}\,dxdy = \int_0^a x(e-1)\,dx = (e-1)\left[\frac{x^2}{2}\right]_0^a = \boxed{\frac{(e-1)a^2}{2}}.$$
🔑 ポイントまとめ
  • (1)：長方形領域では累次積分にそのまま直せる。指数 $a$ が文字でも，$\int (x+y)^a dx = (x+y)^{a+1}/(a+1)$ の公式がそのまま使える（$a\ne -1$，今回は $a>0$ なので問題なし）。
  • (2)：領域と被積分関数の対称性（菱形の4分の1対称，$x^2y^2$ の偶関数性）を使って計算量を $\frac14$ に減らすのが定石。最後の1変数積分は多項式に展開すれば機械的に処理できる。
  • (3)：$D$ が「$x$ を固定すると $y$ が $0$ から $x$ まで動く」三角形領域なので，$y$ の積分を先に行い，$u=y/x$ の置換で $x$ を外に出すのが自然な流れ。
5 広義積分 $\displaystyle\int_0^\infty \frac{\sin x}{x}dx$ と $\displaystyle\int_0^\infty \frac{|\sin x|}{x}dx$

問題文

次の広義積分は収束するかどうかを（証明を付けて）答えよ。収束するならばその値を求めよ。

  1. $\displaystyle\int_0^\infty \frac{\sin x}{x}\,dx$
  2. $\displaystyle\int_0^\infty \frac{|\sin x|}{x}\,dx$
Dirichlet の判定法

$g$ の原始関数 $F(x)=\int_a^x g(t)\,dt$ が有界，かつ $\varphi$ が単調に $0$ へ減少するならば，$\displaystyle\int_a^\infty g(x)\varphi(x)\,dx$ は収束する。

📝 解答 (1) — 収束することの証明

原点付近：$\dfrac{\sin x}{x}$ は $x=0$ で $1$ に収束する（$\lim_{x\to0}\sin x/x=1$）ので，$f(0):=1$ と定めれば $f$ は $[0,1]$ 上連続。よって $\displaystyle\int_0^1 \frac{\sin x}{x}dx$ は通常のリーマン積分として存在する（広義性なし）。

無限遠側：$g(x)=\sin x$，$\varphi(x)=1/x$ に Dirichlet の判定法を適用する。$F(X)=\displaystyle\int_1^X \sin x\,dx = \cos1-\cos X$ は $|F(X)|\le 2$ で有界，$\varphi(x)=1/x$ は単調減少で $x\to\infty$ で $0$ に収束する。よって

$$\int_1^\infty \frac{\sin x}{x}\,dx \ \text{は収束する。}$$

以上より $\displaystyle\int_0^\infty \frac{\sin x}{x}dx = \int_0^1+\int_1^\infty$ は収束する。$\blacksquare$

🧠 値を求める方針
🔄 パラメータを1つ増やして微分する（Feynman のトリック）

$\sin x/x$ 単体では初等的な原始関数が存在しない。そこで $s\ge0$ をパラメータとして $I(s):=\displaystyle\int_0^\infty e^{-sx}\frac{\sin x}{x}dx$ を導入し，$s>0$ では絶対収束するので $s$ で微分できる。微分すると $\sin x/x$ の $x$ が消えて，初等的なラプラス変換 $\int_0^\infty e^{-sx}\sin x\,dx = \dfrac{1}{1+s^2}$ に帰着する。あとは $s$ について積分し戻し，$s\to\infty$ と $s\to0^+$ の極限から定数と目的の値を確定させる。

📝 値の計算

$s>0$ に対し $I(s):=\displaystyle\int_0^\infty e^{-sx}\frac{\sin x}{x}dx$ とおく（$s>0$ では $|e^{-sx}\sin x/x|\le e^{-sx}$ より絶対収束し，$s$ について微分可能）。

$$I'(s) = -\int_0^\infty e^{-sx}\sin x\,dx = -\frac{1}{1+s^2}$$

（$\int_0^\infty e^{-sx}\sin x\,dx=\frac{1}{1+s^2}$ は部分積分2回，またはラプラス変換の公式）。両辺を $s$ で積分すると

$$I(s) = -\arctan s + C \qquad (s>0).$$

$s\to\infty$ のとき $I(s)\to 0$（優収束定理，または直接評価 $|I(s)|\le\int_0^\infty e^{-sx}dx=1/s\to0$）。一方 $-\arctan s+C\to -\pi/2+C$。よって $C=\pi/2$：

$$I(s) = \frac{\pi}{2}-\arctan s \qquad (s>0).$$

もとの積分は $\displaystyle\int_0^\infty\frac{\sin x}{x}dx = \lim_{s\to0^+}I(s)$ に等しいことが知られている（(1) で示した収束性のもと，$s\to0^+$ の極限操作が正当化される：Abel の連続性定理）。したがって

$$\int_0^\infty \frac{\sin x}{x}\,dx = \lim_{s\to0^+}\left(\frac{\pi}{2}-\arctan s\right) = \boxed{\frac{\pi}{2}}.$$
📝 解答 (2) — $\displaystyle\int_0^\infty\frac{|\sin x|}{x}dx$ は発散する

各 $n=1,2,\ldots$ に対し，区間 $[n\pi,(n+1)\pi]$ 上では $x\le(n+1)\pi$ なので

$$\frac{|\sin x|}{x} \geq \frac{|\sin x|}{(n+1)\pi}.$$

また $|\sin x|$ は周期 $\pi$ ごとに同じ形を繰り返すので，$\displaystyle\int_{n\pi}^{(n+1)\pi}|\sin x|\,dx = \int_0^\pi|\sin x|\,dx = 2$（符号を無視すれば $\sin$ の半周期分の面積）。したがって

$$\int_{n\pi}^{(n+1)\pi}\frac{|\sin x|}{x}\,dx \geq \frac{1}{(n+1)\pi}\int_{n\pi}^{(n+1)\pi}|\sin x|\,dx = \frac{2}{(n+1)\pi}.$$

これを $n=1$ から $N$ まで足し合わせると

$$\int_{\pi}^{(N+1)\pi}\frac{|\sin x|}{x}\,dx \geq \sum_{n=1}^{N}\frac{2}{(n+1)\pi} = \frac{2}{\pi}\sum_{n=1}^{N}\frac{1}{n+1}.$$

右辺は調和級数の部分和なので $N\to\infty$ で $+\infty$ に発散する。よって左辺，すなわち $\displaystyle\int_0^\infty\frac{|\sin x|}{x}dx$ も発散する（$+\infty$ に発散）。$\blacksquare$

🔑 ポイントまとめ
  • (1) は条件収束の典型例：符号が交互に振動する $\sin x$ と，単調に $0$ へ減衰する $1/x$ の組み合わせで Dirichlet の判定法が使える。絶対収束はしない（(2) がまさにそれを示している）。
  • 値の計算のテクニック：パラメータ付きの積分 $I(s)=\int e^{-sx}\frac{\sin x}{x}dx$ を導入して微分すると，扱いにくい $\sin x/x$ が扱いやすい $e^{-sx}\sin x$ に化ける。これは Feynman のパラメータ微分法（Leibniz の積分則）の代表例。
  • (2) は「各周期での面積を harmonic に足し合わせる」のが定石：$|\sin x|$ の1周期分の面積が定数（$=2$）である一方，分母 $x$ が線形に増えるので，各項が $1/n$ のオーダーで減衰する調和級数型の和になり発散する。
  • 条件収束 vs 絶対収束：(1)(2) を合わせると，$\int_0^\infty \sin x/x\,dx$ は収束するが絶対収束はしない，すなわち条件収束であることが分かる。

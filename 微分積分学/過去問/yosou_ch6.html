問題 6.1 難易度 ★★☆☆☆

判別式による臨界点の分類

問題

$f(x,y)=x^3+y^3-3xy$ の全ての臨界点を求め、判別式 $pr-q^2$（定理6.12、../ch6.html#extrema）を用いて 各点の種類（極大・極小・鞍点・判定不能）を判定せよ。

この問題の位置づけ — 例6.1・例6.2との違い

Ch.6本文の例6.1（$f=x^2+y^2$、../ch6.html#extrema）と例6.2（$f=x^2-y^2$）は、いずれも 原点ただ1点だけが臨界点になる、判別式の使い方を確認するための最も単純な例だった。 本問で扱う $f(x,y)=x^3+y^3-3xy$ はそれよりも一段実践的な、教科書でも定番の例（いわゆる「デカルトの正葉線」に 対応する曲面）で、臨界点が複数存在し、しかもそれぞれの点で判別式の符号が異なるという構造を持つ。

この問題のもう一つの学びどころは、臨界点を求める連立方程式そのものの解き方にある。 $f_x=0,\,f_y=0$ を素朴に連立させると $y=x^2$ と $x=y^2$ という2つの放物線の交点を求める問題になり、 このままでは手が止まりやすい。片方をもう片方に代入して1変数の方程式に帰着させるという テクニックが必要になる——定理6.12の判定法を当てはめる前段階の「臨界点を確実に全部見つける」計算力も、 本問では合わせて問われている。臨界点が複数あり、かつ点ごとに判定結果が分かれるという構造は、 Ch.6本文の例6.3（$f=xy(x^2+y^2-1)$、9個の臨界点、../ch6.html#extrema）でも 同じ考え方で確認できるので、本問の後に見比べてみるとよい。

模範解答

臨界点を求める：

$$f_x = 3x^2-3y = 0 \ \Rightarrow\ y=x^2, \qquad f_y = 3y^2-3x = 0 \ \Rightarrow\ x=y^2.$$

$y=x^2$ を $x=y^2$ に代入すると

$$x = (x^2)^2 = x^4 \ \Rightarrow\ x^4-x=0 \ \Rightarrow\ x(x^3-1)=0 \ \Rightarrow\ x=0 \text{ または } x=1.$$

$x=0$ のとき $y=x^2=0$ より臨界点 $(0,0)$。$x=1$ のとき $y=x^2=1$ より臨界点 $(1,1)$。 （$x^3-1=0$ の実数解は $x=1$ のみであることに注意——複素数解は実平面上の臨界点には対応しない。） よって臨界点は $(0,0)$ と $(1,1)$ の2点である。

2階偏導関数と判別式：

$$f_{xx}=6x=p, \qquad f_{xy}=-3=q, \qquad f_{yy}=6y=r.$$

$(0,0)$ での判定： $p=6\cdot0=0$, $q=-3$, $r=6\cdot0=0$。

$$pr-q^2 = 0\cdot0-(-3)^2 = -9 < 0.$$

定理6.12の判定法（../ch6.html#extrema）より、$\det H<0$ なので $(0,0)$ は鞍点である。

$(1,1)$ での判定： $p=6\cdot1=6$, $q=-3$, $r=6\cdot1=6$。

$$pr-q^2 = 6\cdot6-(-3)^2 = 36-9 = 27 > 0.$$

$pr-q^2>0$ かつ $p=6>0$ なので、定理6.12の判定法より $(1,1)$ は極小である。

補足 — 臨界点が複数あることの意味

例6.1・例6.2では臨界点が原点1つだけだったため、判別式の判定は「その1点が極大か極小か鞍点か」という 単純な二択（三択）の問題だった。本問のように臨界点が複数ある一般の関数では、判別式の計算を 各臨界点ごとに独立に行う必要がある——$(0,0)$ と $(1,1)$ とで $p,q,r$ の値も判別式の符号も 全く異なる結果になったことからも分かる通り、「1つの臨界点での判定結果を他の臨界点にも当てはめる」ことは できない。試験で複数の臨界点が出てきたときは、面倒でも1点ずつ丁寧に $p,q,r$ を評価し直すこと。

問題 6.2 難易度 ★★★☆☆

2変数テーラー展開の直接計算と近似値の比較

問題

$f(x,y)=e^x\cos y$ の原点まわりの2次のテーラー展開（定理6.6、../ch6.html#taylor2）を求め、 それを用いて $f(0.1,0.1)$ の近似値を計算し、真の値と比較せよ。

この問題の位置づけ — 「臨界点での」展開から「一般の点での」近似計算へ

Ch.6本文で定理6.6・定理6.10が実際に使われる場面は、例6.1・例6.2のようにいずれも臨界点における テーラー展開（1次の項 $f_x,f_y$ が消える場合）で、目的も「極大・極小・鞍点のどれか」を判定することに限られていた。 本問はそれとは異なり、原点が臨界点であるとは限らない一般の点における2次のテーラー展開を計算し、 それを実際の数値近似として使うという、より総合的な応用問題になっている （実際 $f_x(0,0)=1\ne0$ なので原点は臨界点ではない）。

これはCh.2で学んだ1変数のテーラーの定理を、Ch.5の全微分・接平面（定理6.2）の延長線上で2変数へ拡張したものが 定理6.6であり、「テーラー展開は極値判定だけでなく、そもそも関数の近似計算そのものに使える」という 本来の役割を再確認する問題として位置づけられる。

模範解答

0階〜2階の偏導関数を原点で評価する：

$$f(0,0) = e^0\cos0 = 1.$$ $$f_x = e^x\cos y, \quad f_x(0,0)=1.$$ $$f_y = -e^x\sin y, \quad f_y(0,0)=0.$$ $$f_{xx} = e^x\cos y, \quad f_{xx}(0,0)=1=p.$$ $$f_{xy} = -e^x\sin y, \quad f_{xy}(0,0)=0=q.$$ $$f_{yy} = -e^x\cos y, \quad f_{yy}(0,0)=-1=r.$$

定理6.6（../ch6.html#taylor2）より、2次までの近似は

$$f(x,y) \approx f(0,0)+f_x(0,0)x+f_y(0,0)y+\frac12\bigl(px^2+2qxy+ry^2\bigr) = 1+x+\frac12(x^2-y^2).$$

$(x,y)=(0.1,0.1)$ を代入する：

$$f(0.1,0.1) \approx 1+0.1+\frac12\bigl(0.01-0.01\bigr) = 1+0.1+0 = 1.1.$$

真の値との比較：

$$e^{0.1}\cos(0.1) \approx 1.10517\times0.99500 \approx 1.10007.$$

2次近似による値 $1.1$ と真の値 $\approx1.10007$ は非常に近く、その差はおよそ $0.00007$（$7\times10^{-5}$程度）にすぎない。 $(x,y)=(0.1,0.1)$ は原点から十分近い点であり、2次のテーラー展開だけでもきわめて高い精度で $f$ を近似できることが 具体的な数値で確認できる。

補足 — なぜ $x^2$ と $y^2$ の項がちょうど打ち消し合ったのか

今回たまたま $x=y=0.1$ だったため、2次の項 $\dfrac12(x^2-y^2)$ が $\dfrac12(0.01-0.01)=0$ となり、近似値の計算上は 1次近似（$1+x=1.1$）と2次近似が同じ値 $1.1$ になった。これは $p=1,r=-1$ で符号が逆（かつ $q=0$）という $f$ の原点における2階微分係数の特徴（$e^x\cos y$ の $\cos$ 成分が $y$ 方向に「鞍型」の寄与をする）による偶然であり、 一般の $(x,y)$（例えば $x\ne y$）ではこの打ち消し合いは起こらず、2次の項が近似の精度向上に寄与する。

問題 6.3 難易度 ★★★★☆

判別式が0のとき——2次近似だけでは判定できない例

問題

$f(x,y)=x^4+y^4$ と $g(x,y)=x^4-y^4$ について、それぞれ原点における $p,q,r$（定理6.12、../ch6.html#extrema の記法）と判別式 $pr-q^2$ を求めよ。両者とも判別式が同じ値になることを確認した上で、$f$ の原点は大域的最小、 $g$ の原点は鞍点であることを直接（4次の項を見て）判定し、判別式 $pr-q^2=0$ のときは2次近似だけでは 極値の種類を判定できないことを説明せよ。

この問題の位置づけ — 定理6.12の判定法の「空欄」を埋める

定理6.12の判定法（../ch6.html#extrema）には $pr-q^2>0$（極大・極小）と $pr-q^2<0$（鞍点）の 2つの確定的なケースが並んでいるが、Ch.6本文の例6.1・例6.2・例6.3はいずれもこの確定的なケースだけを扱っており、 「$pr-q^2=0$：この判定では決まらない」（定理6.12の証明中でも、連続性の議論が $\det H(a,b)\ne0$ を 前提にしていたことに対応する）が実際にどういう状況なのかは具体例で確認されていなかった。

本問はまさにこの空欄を埋める問題である。$f=x^4+y^4$ と $g=x^4-y^4$ という、係数のうち符号を1つ変えただけの きわめてよく似た2つの関数を用意し、両者の判別式が全く同じ値（$0$）になるにもかかわらず、 実際の極値の種類は正反対（大域的最小 vs 鞍点）であることを示す。これは判別式が2次の項だけの情報しか 見ていないために起こる限界であり、「判別式が $0$ になったら、2次近似より高次の情報（本問では4次の項）を 直接調べる必要がある」という一般的な教訓を、本問を通じて身につけることが目的である。

模範解答

$f(x,y)=x^4+y^4$ の場合：

$$f_x=4x^3, \quad f_y=4y^3.$$

原点で $f_x(0,0)=f_y(0,0)=0$ なので原点は臨界点。

$$f_{xx}=12x^2, \quad f_{xy}=0, \quad f_{yy}=12y^2.$$

原点で $p=0,\ q=0,\ r=0$ なので

$$pr-q^2 = 0\cdot0-0^2 = 0.$$

$g(x,y)=x^4-y^4$ の場合： 同様に

$$g_x=4x^3, \quad g_y=-4y^3$$

より原点は臨界点で、

$$g_{xx}=12x^2, \quad g_{xy}=0, \quad g_{yy}=-12y^2$$

より原点で $p=0,\ q=0,\ r=0$、よって

$$pr-q^2 = 0\cdot0-0^2 = 0.$$

$f$ と $g$ の原点における $p,q,r$ の値、そして判別式 $pr-q^2$ の値は完全に一致する（すべて $0$）。 定理6.12の判定法に従うなら、どちらも「この判定では決まらない」としか言えず、2次近似だけからは $f$ と $g$ の原点での振る舞いの違いを区別できない。

直接（4次の項を見て）判定する：

$f(x,y)=x^4+y^4\ge0$ は任意の $(x,y)$ で成り立ち（4乗はすべて非負）、等号は $(x,y)=(0,0)$ のときに限る。 $f(0,0)=0$ なので、

$$f(x,y) \ge 0 = f(0,0) \quad (\text{任意の }(x,y)\text{ で}), \qquad f(x,y)>f(0,0)\ ((x,y)\ne(0,0)).$$

したがって原点は $f$ の（局所的どころか大域的な）極小点である。

一方 $g$ については、$y=0$ に制限すると

$$g(x,0) = x^4 > 0 = g(0,0) \quad (x\ne0),$$

$x=0$ に制限すると

$$g(0,y) = -y^4 < 0 = g(0,0) \quad (y\ne0)$$

となる。つまり原点のどんなに小さい近傍を取っても、$g$ はその中で $g(0,0)$ より大きい値も小さい値も 両方とる（$x$軸方向に進めば増加、$y$軸方向に進めば減少）。よって原点は $g$ の極大でも極小でもなく、 鞍点である（定義6.8・定理6.9、../ch6.html#extrema）。

教訓 — 判別式 $pr-q^2=0$ は「情報不足」を意味する

$f=x^4+y^4$ と $g=x^4-y^4$ は原点において $p,q,r$（すなわち2次の項の係数）がすべて等しい（すべて $0$）にもかかわらず、 実際の極値の種類は大域的最小と鞍点 という正反対の結果になった。これは2次形式 $\frac12(ph^2+2qhk+rk^2)$ 自体が恒等的に $0$ になってしまい、定理6.12（および補題6.11の2次形式の分類）が 本来頼っている「2次の項の符号がおおむね関数の増減を支配する」という仕組みそのものが機能しなくなっている ためである。判別式が $0$ になったときは、2次近似だけで結論を出そうとせず、本問のように次の次数 （4次など）の項を直接調べるか、あるいは制限した直線・曲線に沿って関数の挙動を具体的に追う、 という追加の議論が必須になる。この教訓は、Ch.6本文の $\det H(a,b)=0$ に関する注記 （../ch6.html#extrema）でも同じ言葉で述べられている。

問題 6.4 難易度 ★★★★★

3次までの2変数テーラー展開（演算子公式の応用）

問題

$f(x,y)=\sin(x+y^2)$ の原点まわりの3次までの2変数テーラー展開を、命題6.5（../ch6.html#taylor2）の 演算子公式 $(h\partial_x+k\partial_y)^nf(a,b)$ を用いて求めよ。

この問題の位置づけ — 演算子公式を3次まで実際に走らせる

Ch.6本文は命題6.5で演算子 $h\partial_x+k\partial_y$ による一般論（定理6.7の一般形の背後にある枠組み）を提示するが、 具体的な数値計算として確認しているのは定理6.6の $n=2$ の場合までにとどまっている。本問はその先、 3次の項までを実際に計算することで、命題6.5・定理6.7の一般形が単なる形式的な表記ではなく、 手を動かして最後まで計算しきれる道具であることを確認する発展問題である。

さらに本問では、演算子公式による力技の計算に加えて、$u=x+y^2$ とおいて1変数のテーラー展開 $\sin u = u-\dfrac{u^3}{6}+\cdots$ に帰着させるという近道の別解も用意する。2通りの独立な方法で 計算し、結果が一致することを確認する——この「別解で検算する」という姿勢は、本予想問題集（第1回〜第6回）を 通じて繰り返し推奨してきた検算習慣であり、全24問シリーズの最終問題である本問はその総仕上げでもある。

模範解答（演算子公式による計算）

原点における偏導関数を次数ごとに計算する。

0次・1次：

$$f=\sin(x+y^2), \qquad f(0,0)=\sin0=0.$$ $$f_x=\cos(x+y^2), \quad f_x(0,0)=\cos0=1.$$ $$f_y=2y\cos(x+y^2), \quad f_y(0,0)=0.$$

2次：

$$f_{xx}=-\sin(x+y^2), \quad f_{xx}(0,0)=0.$$ $$f_{xy}=-2y\sin(x+y^2), \quad f_{xy}(0,0)=0.$$ $$f_{yy}=2\cos(x+y^2)-4y^2\sin(x+y^2), \quad f_{yy}(0,0)=2\cos0-0=2.$$

3次：

$$f_{xxx}=-\cos(x+y^2), \quad f_{xxx}(0,0)=-1.$$ $$f_{xxy}=-2y\cos(x+y^2), \quad f_{xxy}(0,0)=0.$$ $$f_{xyy}=-2\sin(x+y^2)-4y^2\cos(x+y^2), \quad f_{xyy}(0,0)=0.$$

$f_{yyy}$ を計算すると、$f_{yy}=2\cos(x+y^2)-4y^2\sin(x+y^2)$ を $y$ でさらに微分した結果は、 どの項も $y$ または $y^3$ を因子として持つ（$\partial_y\cos(x+y^2)=-2y\sin(x+y^2)$、 $\partial_y\bigl[4y^2\sin(x+y^2)\bigr]=8y\sin(x+y^2)+8y^3\cos(x+y^2)$、いずれも $y$ の因子を含む）ため、

$$f_{yyy}(0,0) = 0.$$

命題6.5の演算子公式は、$n$次の項を $\dfrac1{n!}\displaystyle\sum_{p=0}^n\binom{n}{p}f_{x^py^{n-p}}(0,0)\,x^py^{n-p}$ という形にまとめる。これを次数ごとに適用する。

1次の項：

$$f_x(0,0)x+f_y(0,0)y = 1\cdot x+0\cdot y = x.$$

2次の項：

$$\frac1{2!}\bigl(f_{xx}x^2+2f_{xy}xy+f_{yy}y^2\bigr)\Big|_{(0,0)} = \frac12\bigl(0\cdot x^2+2\cdot0\cdot xy+2\cdot y^2\bigr) = \frac12(2y^2) = y^2.$$

3次の項：

$$\frac1{3!}\bigl(f_{xxx}x^3+3f_{xxy}x^2y+3f_{xyy}xy^2+f_{yyy}y^3\bigr)\Big|_{(0,0)} = \frac16\bigl(-1\cdot x^3+0+0+0\bigr) = -\frac{x^3}{6}.$$

以上をまとめると、3次までの2変数テーラー展開は

$$f(x,y) \approx x+y^2-\frac{x^3}{6}.$$
検算（別解） — $u=x+y^2$ に置き換えて1変数展開に帰着させる

$u=x+y^2$ とおくと $f(x,y)=\sin u$ である。原点近傍では $x,y$ がともに小さいので $u=x+y^2$ も小さく、 1変数のマクローリン展開（Ch.2）

$$\sin u = u-\frac{u^3}{6}+\cdots$$

がそのまま使える。ここで次数の数え方に注意が必要——$u=x+y^2$ の中で $x$ は1次、$y^2$ は2次の量なので、 $u$ 自体は「1次と2次が混ざった量」である。3次までを求めたいので、$u$ と $u^3$ をそれぞれ3次まで展開すればよい。

$u=x+y^2$ 自身はすでに3次以下（$x$: 1次、$y^2$: 2次）なのでそのまま使える。次に $u^3$ を展開すると

$$u^3 = (x+y^2)^3 = x^3+3x^2y^2+3xy^4+y^6.$$

このうち3次以下の項は $x^3$ だけであり、$3x^2y^2$（4次）・$3xy^4$（5次）・$y^6$（6次）はいずれも4次以上なので、 3次までの展開では無視できる。よって

$$u^3 \approx x^3 \quad(\text{3次まで}).$$

したがって

$$\sin u \approx u-\frac{u^3}{6} \approx (x+y^2)-\frac{x^3}{6} = x+y^2-\frac{x^3}{6} \quad(\text{3次まで}).$$

これは演算子公式による計算結果 $x+y^2-\dfrac{x^3}{6}$ と完全に一致する。

2つの解法の意味——力技と近道、そして検算という習慣

演算子公式（命題6.5）による解法は、$f_x,f_y,f_{xx},f_{xy},f_{yy},f_{xxx},f_{xxy},f_{xyy},f_{yyy}$ という 9個もの偏導関数を原点で丁寧に評価する必要があり手間がかかるが、どんな2変数関数にも機械的に適用できる という汎用性がある。一方 $u=x+y^2$ に置き換える別解は、$f$ が「$\sin$」と「$x+y^2$」の合成関数であるという $f$ 固有の構造を見抜いた上での近道であり、計算量は大幅に減るが、どんな関数にも使えるわけではない （合成関数の内側をうまく1つの変数にまとめられる場合に限られる）。

全6回・24問にわたる本予想問題集では、繰り返し「2通りの独立な方法で解いて答えを照合する」という検算の 習慣を推奨してきた。本問はその最後を飾るにふさわしく、力技（演算子公式）と近道（変数変換）という 対照的な2つのアプローチが同じ結論 $x+y^2-\dfrac{x^3}{6}$ に到達することを確認できた—— これは単なる偶然の一致ではなく、命題6.5・定理6.7がテーラー展開の理論として無矛盾であることの 具体的な現れでもある。

自力確認チェックリスト

本回（第6回）は全6回・24問からなる本編予想問題シリーズの最終回である。以下の4項目は、Ch.6だけでなく Ch.1〜Ch.6全体を通じて身につけてほしい2変数の微分積分の総仕上げの視点でもある。

  • 臨界点を求める連立方程式（$f_x=0,f_y=0$）を、代入によって1変数の方程式に帰着させて確実に全て求め、判別式 $pr-q^2$（定理6.12）を各臨界点ごとに独立に評価して極大・極小・鞍点を判定できる（問題6.1）。
